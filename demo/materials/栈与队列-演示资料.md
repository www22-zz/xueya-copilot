# 【演示】数据结构：栈与队列

## 1. 线性结构与栈

栈是一种只允许在一端进行插入和删除的线性结构。栈遵循后进先出（LIFO）原则。进行操作的一端称为栈顶，另一端称为栈底。

入栈（push）将元素加入栈顶，出栈（pop）移除栈顶元素。读取栈顶而不删除称为 peek。

例子：依次将 A、B、C 入栈后，连续出栈的顺序为 C、B、A。函数调用、撤销操作和括号匹配可以用栈表达。

使用 Python 列表实现栈时，append 在尾端入栈，pop 在尾端出栈。列表尾端 append 的均摊时间复杂度为 O(1)，尾端 pop 的时间复杂度为 O(1)。空栈不能直接执行 pop，应先检查是否有元素。

## 2. 队列

队列是一种从一端插入、从另一端删除的线性结构。队列遵循先进先出（FIFO）原则。插入的一端称为队尾，删除的一端称为队头。

例子：依次将 A、B、C 入队后，连续出队的顺序为 A、B、C。排队服务和广度优先遍历（BFS）常用队列保存等待处理的对象。

使用 Python 的 collections.deque 可以在两端高效增删：append 将元素加入队尾，popleft 从队头取出，二者的时间复杂度均为 O(1)。普通列表的 pop(0) 需要搬移后续元素，时间复杂度为 O(n)。

## 3. 栈与队列的对比

栈的删除端与插入端相同，队列的删除端与插入端不同。栈遵循后进先出，队列遵循先进先出。这是二者最重要的区别。

同样处理 A、B、C 三个元素，栈更早取出最后加入的 C，队列更早取出最先加入的 A。

## 4. 循环队列与边界

用定长数组实现循环队列时，指针通过取模运算回到数组起点。若约定牺牲一个空位，并让 rear 指向下一次插入位置、front 指向下一次删除位置，则队空条件为 front == rear，队满条件为 (rear + 1) % capacity == front。

容量为 capacity 的数组在这个约定下，最多存放 capacity - 1 个元素。使用其他实现约定时，判空和判满公式可能不同，应先确认约定。

## 5. 自测与参考

问题一：依次将 A、B、C 入栈，第一次出栈得到什么？参考答案：C，因为最后入栈的元素最先出栈。

问题二：依次将 A、B、C 入队，第一次出队得到什么？参考答案：A，因为最先入队的元素最先出队。

问题三：普通列表的 pop(0) 为什么比 deque.popleft 更慢？参考答案：列表需要搬移后续元素，耗时随元素数量增长；deque 可以在端部直接删除。
