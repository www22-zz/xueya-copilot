# 学涯演示与验收指南

2026-10-17。适用当前 main 加 F 分支；[技术报告](../reports/学涯Copilot技术报告.md)与[未完成项](../delivery/F-问题与待验证清单.md)一起交付。

## 1. 准备

1. 获取代码，安装 Python 3.11 或更新版本。Windows 双击根目录 `启动学涯.cmd`，首次会准备依赖并打开实际 HTTP 页面。不要直接打开 `frontend/index.html`；`file://` 只是预览，不能连接本地服务。
2. 开发终端也可先 `python -m pip install -r requirements.lock`，再 `python -m backend.xueya.server`。以实际启动输出的网址为准，默认本机 4173 端口。
3. 不演示私人资料。先备份现有数据；需要全新数据时，先停止旧服务，在终端设置 `$env:XUEYA_DATA_DIR='C:\临时目录\xueya-demo'` 后启动。主配置支持该环境变量；核对启动信息，不删除旧库。
4. 运行 `python -m scripts.build_quality_materials`，样例在 `test-results/f-quality/materials`。这是原创演示资料，不是教师课件。
5. 第一轮演示可不配模型，使用原文摘录与手动题目；页面会明确显示能力边界。真实 API 生成需先确认当次预算、模型配置和失败停止规则，未经授权不执行付费演示。

## 2. 约十五分钟演示顺序

| 时间 | 操作 | 讲解与验收点 |
| --- | --- | --- |
| 0～2 分钟 | 打开学习空间，新建/选择演示课程，上传 `linear.md`、`trees.md`、`lecture.docx` | 等资料作业完成，打开原件和解析内容；资料是后续证据来源 |
| 2～4 分钟 | 选择资料，问“队列按照什么次序移除元素？”，打开引用 | 无模型显示原文摘录；有模型时核对答案与引文是否支持，不能只看引用按钮存在 |
| 4～6 分钟 | 在学习包/总结区预览，再确认保存；进入笔记写下自己的理解 | 预览不等于保存；刷新后确认已保存内容还在，检查出处 |
| 6～9 分钟 | 题库创建一题：队列次序，选项先进先出/后进先出，引用资料，审核通过；测验故意答错 | 看评分与诊断，修改错因并再次读取；使用手动题目时明确说明，不伪装模型生成 |
| 9～11 分钟 | 建立有出处的复习卡，进入到期队列，完成评分 | 解释新的到期时间是调度结果，不能声称已证明提高成绩 |
| 11～13 分钟 | 图谱确认概念及证据，预览计划，查看日可用时间，再采纳 | 检查计划有具体安排与剩余量；有图谱关系时检查前置关系与循环限制 |
| 13～15 分钟 | 展示生成停止/异常提示及刷新恢复；展示 F 的结果和失败清单 | 受控回放须标注；不把三种短问法失败隐藏，说明接下来 G4 改进 |

模型相关按钮在无能力配置时应说明不可用；不为演示强行把不可用状态改成成功。真实生成可作为另一次有预算的演示，记录实际等待和失败，不能用预制答案冒充实时响应。

## 3. 可复现自动验收

在安装依赖后的项目根目录执行：

```powershell
python -m pip check
python -m pytest -q
node scripts/test.js --frontend
node tests/e2e/browser.js
node tests/e2e/workspace.js
node tests/e2e/platform.js
python -m scripts.check_learning_browser
python -m scripts.check_quality --split test --repeats 3
python -m scripts.run_c_local_experiments --output test-results/f-quality/c-rules
```

Node 仅用于保留的前端回归，需要本机 Node 和 Chrome；不是后端启动依赖。Python 浏览器检查同样需要 Chrome。具体浏览器寻找规则以脚本为准，可设置 `CHROME_PATH` 指向实际浏览器。所有新增 F 脚本及后端测试使用 Python，离线评测不读 `.env`、不计费。

本轮已实际通过的结果见报告，未来再次执行须保留自己的日期/版本/结果，不能用旧“190 passed”代替当前检查。GitHub CI 覆盖后端、前端单元及离线诊断，浏览器在本机另验。

## 4. 故障和恢复检查

- 上传后看任务状态；若解析失败，保留错误并核对格式/能力，不将扫描图片当作已解析文字。
- 模型不可用时先看能力设置、服务运行地址和错误说明，不输出 `.env` 内容；不自动重试付费请求。
- 生成中停止后，检查未产生部分保存结果，重试应是用户明确发起的新操作。
- 刷新确认笔记、作答和复习记录仍在；重复确认不应增加重复记录。
- 自动恢复测试 `test_actual_course_learning_loop_survives_backup_restore` 已验证真实有内容的备份恢复到新目录。手工备份操作请按现有备份文档进行，恢复到独立空目录，不覆盖个人数据库。

课程包导出/导入是下一轮 G1 配合 F 的增强验收，**当前整体备份不等同于可分享的课程包**。
