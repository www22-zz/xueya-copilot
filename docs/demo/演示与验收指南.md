# 演示与验收指南

## 准备

按 [README](../../README.md) 启动服务，使用独立演示数据目录。新目录会准备共享课程，待知识库导入完成再检索。也可用 `scripts.build_quality_materials` 生成原创验收资料；生成数据位于被忽略的 `test-results/`。

模型未配置时展示实际原文检索和摘录；真实问答、语音或图像演示使用已配置 API，记录实际结果和费用。不要展示 `.env` 内容，不把受控模型或预录结果冒充实时真实模型。

## 演示路线

1. 进入学习空间，选择课程，在知识库查看或上传资料，等待处理完成并打开原文。
2. 选择资料范围提问，核对回答引用与页码；验证证据不足时的提示，并演示停止生成。
3. 进入练习与错题页作答、查看解析与复习记录；刷新验证记录仍在。
4. 按当前界面和配置展示可用学习服务：候选题审核、学习包、记忆卡、自评、概念关系和计划；预览后再明确采纳。
5. 查看设置中的任务、服务能力和用量，区分未配置、失败、取消与结果未知。
6. 展示软件回归和离线评测，包括未达标问题及浏览器尚未验证的限制。[最终交付状态](../delivery/FINAL-DELIVERY.md)。

高级学习和媒体入口取决于当前页面实际开放情况；服务接口见 [学习契约](../contracts/learning-services.md)。没有可用入口或外部服务时说明边界，不临时修改界面状态冒充通过。

## 自动验收

```powershell
.venv/Scripts/python.exe -m pip check
.venv/Scripts/python.exe -m pytest -q
node scripts/test.js --frontend
.venv/Scripts/python.exe -m backend.xueya.mcp_server --check
.venv/Scripts/python.exe -m scripts.check_quality --repeats 1
```

可选实际浏览器检查为 `node tests/e2e/browser.js`、`workspace.js`、`platform.js`，需要 Playwright 与浏览器。当前本机缺少 Playwright，不能把历史浏览器记录算成本次通过。真实模型和人工审核单独验收，软件测试使用临时数据和受控上游。

## 恢复与交付核对

- 上传失败核对格式和后台作业，不把扫描图片当已提取正文。
- 取消后未核验流式内容不保存；未知远程结果先检查回执与实际用量。
- 刷新核对记录、版本和重复操作结果；备份恢复遵循 [平台指南](../platform-guide.md)，恢复到新目录。
- 交付源码、依赖锁、测试与夹具、评测资料、共享课件、正式文档；排除 `.env`、私人数据库、依赖目录、日志和生成结果。
- 技术实现、评测方法与限制见 [技术报告](../reports/学涯Copilot技术报告.md)。
