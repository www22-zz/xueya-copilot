## 核心文件与复现

- backend/xueya/practice_catalog.py：固定来源目录及历史兼容。
- backend/agent/exam408_adapted.py、exam408_cases.py、exam408_authored.py：独立题目、解答和评分。
- backend/agent/exam408_topics.py：25章显式映射，未归类即构建报错。
- backend/xueya/data/exam408_selection.json：纯历史考点元数据；exam408_sources.json：来源URL；exam408_bank.json：最终完整题库。
- scripts/build_exam408_bank.py：从仓库源码确定性构建，--check逐字段比较内容与结构。
- frontend/js/practice-hub.js、frontend/css/practice-hub.css：首页及资料承接页；practice-view.js：筛选、作答、自评、笔记。
- tests/python/test_practice_redesign.py：8项专项，含独立数值计算核对；scripts/check_practice_redesign_browser.py：真实Chrome验收。

运行命令：

```powershell
.venv/Scripts/python.exe -X utf8 -m scripts.build_exam408_bank --check
.venv/Scripts/python.exe -X utf8 -m pytest -q -p no:cacheprovider
node scripts/test.js --frontend
.venv/Scripts/python.exe -X utf8 -m scripts.check_practice_redesign_browser
```
