# P5 聊天接入与交付

## 使用

原有资料问答、SSE、图片与录音路径保持。聊天回答下新增“开始章节学习 / 错题巩固 / 跨章节备考”，显式进入持久化运行。章节优先使用该回答引用的来源；其他场景使用当前课程。准备完成后显示无答案练习或备考计划，确认后才写入。用户可以提交真实答案、确认错因、更新计划，以及在步骤边界暂停/恢复。未知付费结果需要单独勾选确认再继续。

计划版本、已完成步骤和运行进度在聊天内可见。刷新浏览器恢复当前会话的任务查询；切换课程/会话不会把旧任务结果写到新会话。主观题仍使用既有人工评分入口。缺题/缺图谱会给出补充提示，来源失效要求新建任务。确认前若成绩、图谱、题库等学习上下文已变化，拒绝采纳旧预览，要求重新预览。

## 开关

- AI_AGENT_PLANNING_ENABLED：原 P1 规划总开关。
- AI_AGENT_DURABLE_ENABLED：新增持久化入口。
- AI_AGENT_INTERACTIVE_ENABLED：练习、错因与计划确认。
- AI_AGENT_ROLLOUT_PERCENT：0–100，按用户+课程稳定分桶；默认 100，设 0 可停用新增入口。

停用保留原问答路径及已有运行查询、暂停和取消；后台在下一步入口暂停。开关通过 GET /api/learning/agent-runs/features 返回，前端无服务或无密钥时不显示新建入口。

## 真实 API 验证记录

用户明确授权本轮总预算不超过 1 元。2026-10-21 在独立临时数据库调用真实 mimo-v2.6-flash 两次，完成第一次 search_materials，第二次响应无法解析，流程安全停止（partial / AI_INVALID_RESPONSE），没有自动重试。

已发现并修复 ScopedModel 遗失 responseFormat 的问题：现在把 JSON 模式传到真实 provider，并补充实际 transport 断言。修复版真实复测等待额外明确授权（项目规定“不自动付费重试”）；因此尚不能把本次记录称为真实端到端通过。

两次 usage：1593 输入 / 239 输出；1879 输入 / 159 输出。按[小米官方实时定价表](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/text-generation/batch-api) flash 未缓存输入 1 元、输出 2 元/百万 tokens，推算约 0.004268 元，供应商账单为准。测试以更高的 10/10 费率累计预留 0.23532 元，低于 1 元。密钥仅从原 .env 读取，没有输出或写入新文件。复测脚本会扣除既有预留，继续约束累计不超过授权预算。

## 实际边界

动态阶段自主选择只读工具；写入、真实作答及错因确认均由用户操作绑定，模型不能替代。学习状态来自现有评分和规划规则；新成绩、日期、时间在用户更新/重排时重新读取并生成预览。一次答对不等于掌握。已有材料目录沿用 48 条上限，章节/备考范围受该上下文限制。尚未做大规模模型效果评测，不扩大测试。
