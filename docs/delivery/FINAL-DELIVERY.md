- 完整测试、固定评测资料、原始研究基线、导入维护工具、共享课件与演示材料。

## 已知限制

1. 真实课程质量、OCR／ASR／TTS 效果、人工审题和实际学习收益需要独立验收；合成实验和受控模型不能替代这些结论。
2. 模型返回 JSON 数组时，`AnswerService.answer` 可能抛 AttributeError；非法字符串 rubric 项也可能绕过领域错误。尚未修复，不在本轮清理中改变错误码或状态码。
3. 文档导入随机 UUID 参与片段 ID；同分检索按 ID 排序，两次独立导入可能返回不同尾部证据。通过数与召回不能证明逐条结果完全稳定。
4. 曾出现两条异步 socket／transport 析构警告，随后 MCP 专项和完整严格警告复查均通过；来源尚未定位，不宣称已修复。
5. 本机账号没有云同步。音视频、图片和可选检索服务取决于配置，未配置时不能假装成功；视频不代表完整理解音轨与所有画面。
6. 历史兼容工厂、部分长 HTML 模板和大型流程仍有维护成本，后续修改需继续遵守行为保持和专项验证。
