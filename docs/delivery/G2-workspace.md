## 实现检查点

已显式快进集成 G1 的公共提交，G2 PR 以 G1 分支为审查基线。

- `/api/platform/library/*` 沿用同源/token、SQLite entities/revisions 与 JobQueue，无 schema 迁移、第二套队列或账本。
- 文字导入和批量文件导入进入 B 解析；网址导入为普通 CPU 后台作业，再创建 B 解析作业。保存原 URL、最终 URL、抓取时间、正文 SHA-256 与不可变原件快照；显式刷新创建新资料版本，失败保留旧资料。
- 抓取限制 http/https、80/443、公开 DNS 全答案、逐跳检查并固定连接 IP、TLS 主机验证、3 次重定向、1MB/超时；不访问登录凭据、不执行网页脚本、不信任系统 HTTP 代理。
- 课程目标/先修/考试范围/章节保存到同库版本化 artifact；资料移章、移出本章、归档/恢复需预览确认；跨课程复用只共享不可变原件 hash，创建独立文档/来源/索引，不复制成绩。可选择复用成功后归档原记录，目标失败不移出源课程。
- 资料阅读器展示真实结构块/页或字符位置、正文查找、历史版本和原件下载；退役派生正文可作为历史快照读取，不恢复为当前证据。章筛选可直接进入本章学习。
- 媒体原件沿用 C 仓库，支持播放/图片、实际片段跳转、Range、明确核对的讲义页/片段关联。旧媒体记录可兼容读取，不伪造逐字时间、页码或整段视频理解。
- 归档资料从 B 和主聊天排除，完成前再次检查；主聊天新增可选 documentIds，省略兼容旧请求、空数组明确不使用任何资料。与 C 范围按课程/会话一致，刷新保留，未迁移旧记录不删除。
