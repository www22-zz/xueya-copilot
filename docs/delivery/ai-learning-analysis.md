# AI 学习分析交付

日期：2026-10-27。基于最新 origin/main（3b73f50）建立 codex/ai-learning-analysis 分支。新增 Python 领域与平台适配，前端继续使用 HTML/CSS/JavaScript；统一入口仍是 backend/xueya/server.py。

## 使用

进入学习空间顶部「学习分析」，选择最近7天、30天或全部历史及题库，选择是否结合已保存的随手记，点击「开始分析」。生成前先同步本地练习操作。没有所选范围的练习记录时提示先去练习，不调用模型。

报告包含真实作答统计、AI 总结、薄弱点、进展、练习模式、覆盖情况和下一步建议。点击题目按钮会打开当前账号对应题目与状态。报告保存生成时快照，继续练习不会改写旧报告；有新记录时提示重新生成。历史报告可查看、继续追问，追问仍依据原报告截止时的记录。

每份报告、作业和对话均按账号隔离。使用现有 JobQueue、API 资源许可、执行预算、模型账本、SQLite entities/revisions。刷新或重启可恢复历史与任务，不创建第二套后端或账本。模型生成纯文本结构化内容并校验真实题目引用；前端转义输出，模型 HTML 不能执行。模型调用明确关闭额外思考输出，以适合有界结构化分析。

## 统计口径

- Asia/Shanghai 自然日，截止到快照生成时刻；7天/30天提供前一等长窗口的整体及逐题对比。
- 单选、填空统计作答和正确数；算法、面试与其他掌握状态为自评，分开显示。
- 填空「此答案也正确」修改原作答，计入原日期，不增加次数；同一作答重复纠正不重复计数。
- 同题反复作答不能等同独立样本，未做过的题不能判断能力；没有学习时长与完整解题过程时明确限制。
- 随手记每题最多240字，快照过大时明确省略摘录和明细，保留整体统计。
