# 可调宽度的对话历史侧栏

日期：2026-10-20。用户要求参考给定豆包截图，仅展示对话历史，不增加定时任务、插件或云盘等入口。

## 行为

- 桌面问答页的历史栏固定在屏幕最左侧，从顶部延伸至底部；默认约为窗口宽度的20%，过窄窗口保持180px最低可用宽度。
- 沿右边缘拖动即可调宽，聊天主区、课程和导航同步让出空间。历史列表独立滚动，底部预留原“设置”入口的位置。只保留已有历史、搜索、新建与会话切换。
- 调整后在当前浏览器记住像素宽度；刷新后恢复。双击边缘恢复20%默认值。聚焦分隔条时，左右方向键每次调16px，Home/End取上下限。宽度最大不超过窗口45%，并为主内容保留至少480px的空间。
- 760px及以下改为“对话历史”按钮打开左侧抽屉，不横向挤压聊天。可用关闭、Escape、点击遮罩或选择会话收起，关闭后焦点回到入口；Tab限制在打开的历史抽屉内。抽屉盖在顶部栏及原设置按钮之上，关闭按钮可实际点击。
- 仅问答页启用，其他学习页面和首页保持原布局；不改变消息、课程、附件、API或数据库。宽度偏好是本机浏览器设置，不随课程数据跨设备同步。

## 代码与验证

- 新模块：`frontend/js/chat-history-layout.js`；样式：`frontend/css/chat-history-layout.css`。
- `python -m scripts.check_history_layout_browser` 使用45个临时会话验证：1440px下默认宽288px、高1000px、位置(0,0)；真实鼠标拖动到388px、刷新恢复、键盘与边界、双击复位；搜索与切换；离开问答解除布局；390px明暗主题抽屉、遮挡命中、关闭焦点及会话选择。
- 原有前端41项规则、输入框/录音/粘贴专项和发送图片专项继续通过。所有数据与浏览器配置均隔离，不触碰用户实际会话，不调用真实收费API。
