# PDF 教材换库与检索优化

本变更复用现有 RAG、资料生命周期、SQLite、FileStore、CPU/API作业和调用账本，没有新增数据库、根路由或本地模型。

## 大文件与扫描页

`POST /api/platform/knowledge/upload` 与 `/api/platform/rag/upload` 的 PDF 上限为64MiB；PPTX/DOCX仍为10MiB，TXT/Markdown为1MiB。服务端接收、RAG上传和隔离解析使用相同限制。旧兼容 `/api/parse` 不随本变更扩容。

PDF仍按文件实际页码从1开始引用；封面、目录和正文均计入，因此PDF页码可能不同于印刷页码。图像扫描页没有文字时保留 `needsOcr`，不会生成虚假知识片段。知识库页面显示扫描/OCR状态，零片段资料不能用于问答或完成换库。

## 显式分批OCR

现有 `knowledge/process`（action=ocr）及 `rag/ocr` 可选传入 `pages:[1,2,...]`，必须是当前资料仍待识别的真实页码，每次1至64个且不重复。未传时保留旧行为，待识别页超过64时拒绝。页面每次只提交接下来最多16页，仍需外部调用确认，不隐式连续调用整本教材。

选择页绑定原资料版本、Provider identity和幂等键；同键换页冲突，取消/未知请求不自动重放。大于10MiB的原件仅把本批所选页面构成临时PDF发送给OCR，临时请求仍限10MiB；若所选页仍超限，返回 `OCR_BATCH_TOO_LARGE`，应减少页数。响应的临时0起始页码映射回原书实际页码；原件hash不变，未识别页的原文本、结构块与方法保留。

接口适配与受控响应测试不等于真实OCR质量验收。服务、模型、凭据和预算没有落实前，不发送真实请求；Provider配置仍按 `.env.example`。

## 预览后更换旧PPT

- `POST knowledge/replacement-preview`：`{courseId,targetDocumentId,oldDocumentIds:[...]}`。新资料必须是本课程有效PDF，具有可核对来源且没有待识别页；旧资料仅允许本课程有效PPTX。返回本机预览ID、目标/旧资料名称、文件hash、内容修订和实体版本，有效期1小时。
- `POST knowledge/replacement-apply`：`{courseId,previewId,confirmed:true}`。在单一事务中复核新PDF可用性及所有版本，再使用原RAG remove退役旧PPT资料和当前来源。任何版本冲突均不部分移除。重复确认返回相同回执。

原件和版本保留供恢复；其他课程、笔记和学习记录不属于此操作的删除范围。新PDF为空、识别未完成、预览过期、跨课程或版本变化时拒绝换库。此保护不构成“PDF全部内容已独立人审”的承诺。

## 免费检索优化

词法、向量同分及RRF合并排序使用资料标题、文件hash、实际页码和字符位置优先于随机导入ID，使同内容重新导入后的证据顺序更稳定。增加前序/先序/先根、二分/折半查找、散列/哈希表及常用英文算法术语的透明同义词匹配；不同遍历顺序仍分开。没有在本地安装或训练Embedding模型，也不伪造未配置的向量结果。
