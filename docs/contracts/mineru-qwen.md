# MinerU / Qwen 教材构建

本次扩展复用 SQLite、FileStore、作业队列、权限与调用账本，不新增本地模型。

## 配置

将根目录 `.env.moark.example` 中的新增服务项追加到已有本机 `.env`，仅填写 `RAG_OCR_API_KEY`、`RAG_EMBEDDING_API_KEY`。保留已经可用的聊天配置，不需要再次提供MiMO密钥，不要用模板覆盖已有 `.env`，也不要复制私人数据库。隔离工作目录在本机复用既有的 `MIMO_API_KEY/MIMO_BASE_URL/MIMO_MODEL`，只补空项，不外发或打印凭据。

配置模型名称必须与账户的 API 面板一致。示例中的 `MinerU2.5-Pro` 待真实账户确认；公共文档示例仍为 `MinerU2.5`。Qwen 2B 使用2048维，8B使用4096维；切换服务、模型、维度或修订后显式重建索引。

已核对的协议依据：[模力方舟文档解析](https://www.moark.com/docs/products/apis/documents/pdf)、[向量化](https://www.moark.com/docs/products/apis/embeddings/)、[Qwen 官方模型](https://github.com/QwenLM/Qwen3-VL-Embedding)。本地受控测试不能证明具体账户的 Pro 模型兼容性、额度或真实解析质量。

## 使用

1. 启动此工作目录的主服务，进入课程资料，上传资料。新增 UI 传 `review=1`，解析完成后等待校正，不自动启动题库生成。
2. 扫描 PDF 选择“处理 → 选择识别页”，输入如 `84-98`，每批1至20页，明确确认外部处理。只允许当前待识别页；已有 OCR 教材若要对比，请在独立测试课程上传10至20页的原件子集，不覆盖当前教材。
3. 打开“校正与确认”，下载原件对照，选择正文块进行修正。保存产生内容修订，保留原始解析结果及修订记录，旧向量失效。
4. 核对当前提取文字后勾选并确认此修订，再建立向量索引。未识别页仍显示待处理，确认不表示全书已经人工审核。
5. 在“测试知识库检索”输入问题。关键词不调用模型；混合或向量检索需要确认将问题发送给外部服务。问答继续使用已有证据与引用链路。

## 兼容与恢复

- 新增既有 knowledge 分发下的 `POST review-confirm`：documentId、version、confirmed=true。旧上传调用不传review时保持既有行为；新UI明确进入复核模式。目录追加reviewReady、knowledgeReview及模型能力信息。
- 复核资料在当前修订未确认时不进入RAG召回、来源读取、Agent资料选择或向量索引。编辑、OCR、重新解析都会改变修订，需再次确认。
- MinerU返回的segments可能按语义分段，不能把index冒充页码。当前适配将本批选页逐页生成单页PDF并提交，绑定原件hash与原页。其速度与质量需要真实小样本验证。
- 每页远端任务ID与原始响应保留在既有存储中。超时不自动重提；用户主动继续同一批时，已完成页复用缓存，有任务ID的页只查询原任务。提交结果未知且没有任务ID时拒绝重放，先在平台核对。
- 原有90秒作业期限及模型调用次数预算保持；较慢或超过单次调用预算的批次可能显示unknown，之后须由用户主动核对和继续。再次选择同一批可复用已完成页并查询已知任务。没有宣称整批必然一次完成。
- 第一阶段索引输入为校正文字。Qwen多模态模型的图像索引、临时图像资源永久化和视觉问答尚未接通；不把文字向量索引称为完整多模态RAG。
- 原始OCR Markdown可能含临时图像链接，不能据此承诺图片永久可用。当前页面按纯文本转义展示。
