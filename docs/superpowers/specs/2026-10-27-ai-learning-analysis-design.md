# AI 学习分析

用户已确认新增 AI 学习分析，并授权立即实现。真实 API 验收最多五次、合计不超过人民币五元。

## 范围与体验

学习空间新增「AI 学习分析」，支持最近 7 天、30 天、全部历史及三个题库范围。生成前同步当前账号的练习记录；可选择是否附带已保存的随手记。展示真实统计、AI 总结、薄弱点、进步、学习模式和下一步建议。建议关联真实题目，点击回到对应题目。报告按账号保存，支持历史阅读和围绕报告继续追问。

沿用现有浅蓝紫配色、字体和按钮；正文为主栏，分析范围和历史为侧栏，手机单列。顶部明确展示统计截止时间，避免历史报告被误解为实时结果。

## 数据与边界

Python 领域逻辑放在 backend/agent/practice_analysis.py，主平台适配放在 backend/xueya/practice_analysis.py。使用当前练习事件、题库和状态，不恢复已删除的旧学习模块。按 Asia/Shanghai 自然日筛选，当前时间为截止时间。纠正填空结果作用于原作答，不额外增加作答次数。客观题记录与自评分别统计。最近时间段和前一等长时间段分别统计；全部历史没有同期对比。

客观事实由程序汇总，诊断和建议仅由外部 AI 生成。AI 收到有界、带时间和题目 ID 的快照；数据和随手记均为不可信内容。样本不足、未记录解题过程时明确限制，不宣称确定错因、真实能力或学习成效。模型返回结构化 JSON，校验字段、长度与题目引用；失败不伪造报告。

## 可靠性

沿用主平台 JobQueue、SQLite、账号隔离、并发许可、预算和调用账本。生成和追问各一次模型调用，无自动付费重试。提交使用幂等键，账号同时只运行一个分析任务；刷新后通过服务端列表找回任务和报告。未知结果显示核对提示。前端转义模型文本，题目链接由已校验 ID 构造，不能执行模型 HTML 或 URL。

## 实施与验证顺序

1. 实现快照、纠错统计、结构校验和提示词。
2. 接入可恢复作业、报告历史、追问及现有授权。
3. 增加分析页、导航、范围筛选、历史、题目跳转和追问。
4. 测试时间边界、纠错、少样本、自评区分、幂等、账号隔离、模型失败、恶意引用、刷新恢复及桌面手机实际界面。
5. 运行全部 Python、原前端回归及相关浏览器验收；在授权预算内实际调用并记录结果。
