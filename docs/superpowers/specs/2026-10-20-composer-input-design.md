# 提问附件与麦克风输入

按用户给定截图及“现在补齐”的授权实施，保留现有界面和其他功能。

1. 原“图片”按钮改为加号，点击选择图片或 PDF、DOCX、TXT、Markdown 文件。图片保留图文问答；文档经现有 Python 资料解析接口处理，原件及版本进入当前课程，正文作为本次问题依据。最多四个附件，错误可见，重试复用已解析文档。
2. 原“语音”按钮改成用户参考的线性麦克风图标。点击申请麦克风，录音时显示计时、停止及取消；最长一分钟。停止后浏览器转换为 16kHz 单声道 PCM WAV，调用现有 media/upload、media/transcribe，识别模型固定为 mimo-v2.5-asr。使用现有权限、并发和账本。
3. 转写结果加入可编辑输入框，用户按发送才交由 mimo-v2.6-flash 思考；不自动发给 LLM、不冒充课程原文。支持录音权限拒绝、取消、超长和识别失败后的显式重试。课程/会话或页面离开时停止并丢弃录音，避免跨课程写入；录音期间禁止切课和发送。
4. 保留旧音频附件适配供兼容，主界面不再提供选择音频文件的语音按钮。密钥继续仅存 .env，不写前端、不改用户已配置的密钥。本次验证只使用受控 API 和浏览器生成的测试音频，真实模型质量不做未经预算授权的付费测试。

验证：前端规则、全量 Python；实际浏览器验证加号文件/图片、真实 MediaRecorder 流、PCM 转换、ASR 模型请求、编辑转写后 LLM 请求、取消及拒绝、手机和明暗主题。截图和运行数据留在忽略的 test-results/。
