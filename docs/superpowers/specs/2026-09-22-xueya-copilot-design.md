# 学涯 Copilot 设计规格

## 1. 产品概述
**产品名称**：学涯 Copilot
**一句话定位**：基于课程知识库的 AI 学习副驾，为大学生提供可追溯的课程问答、知识整理与个性化复习支持。
**目标用户**：
- 备考或日常学习的大学生
- 需要整理课程资料、快速检索重点的学生
- 希望获得课程练习和复习计划的学习者

## 2. 目标与成功标准

### 2.1 产品目标
1. 将课程资料转化为可检索、可引用的课程知识库。
2. 帮助学生用自然语言快速获得基于资料的答案。
3. 将一次问答延伸为知识卡片、练习题和复习计划。
4. 以完整 Web 产品展示 RAG、多轮对话和 AI 生成能力。

### 2.2 成功标准
- AI 回答基于已上传资料，并显示可点击的原文引用。
- 新用户可以独立完成“上传资料—提问—查看来源—练习—复习”的完整流程。
- 检索不到资料时明确告知“未找到”，不编造答案。
- 作品在演示环境中稳定完成核心流程，界面清晰、状态明确。

## 3. 范围

### 3.1 第一版必须完成
1. 课程空间管理：创建课程、选择课程、查看课程概览。
2. 知识库管理：上传资料、显示解析状态、查看文档和章节。
3. AI 问答：多轮对话、基于课程资料的回答、答案引用和原文定位。
4. 知识卡片：从回答或选中的原文提取重点概念。
5. 练习题：根据知识点生成选择题或简答题并显示解析。
6. 复习计划：根据考试时间和目标生成分阶段复习安排。

### 3.2 暂不包含
- 视频、音频和复杂图片解析
- 语音输入与语音输出
- 复杂组织权限、支付和真实社交功能
- 真实大规模生产部署

## 4. 技术架构
采用前后端分离结构。
- **前端**：React + TypeScript，负责课程空间、知识库、对话、练习和复习计划界面。
- **后端**：Python FastAPI，负责资料解析、检索、AI 生成和业务接口。
- **数据库**：关系型数据库保存用户、课程、文档、对话和学习记录；向量数据库保存文档切片和语义向量。
- **AI 服务**：统一封装大模型调用，支持切换供应商；演示环境提供无外部 AI 服务时的本地演示响应。

### 4.1 组件边界
1. `CourseSpace`：课程空间入口。
2. `DocumentUploader`：资料上传与解析状态。
3. `KnowledgeLibrary`：文档、章节和知识点管理。
4. `ChatWorkspace`：多轮提问与回答。
5. `CitationViewer`：答案引用与原文定位。
6. `KnowledgeCard`：重点知识整理。
7. `PracticeGenerator`：练习题生成与答题。
8. `StudyPlanner`：考试时间和复习计划。

后端服务：
1. `IngestionService`：解析、分块、向量化和入库。
2. `RetrievalService`：语义检索、重排和引用片段关联。
3. `GenerationService`：提示词组装、模型调用和答案输出。
4. `PracticeService`：练习题生成、批改和解析。
5. `PlanService`：复习计划生成与更新。

## 5. 数据流
1. 上传资料后解析为文本，按语义边界分块。
2. 文本切片生成向量，并与文档、章节、页码和原文位置写入知识库。
3. 用户提问后进行课程内语义检索，返回高相关度片段。
4. `GenerationService` 使用片段、历史对话和用户目标生成回答。
5. 回答中的每条结论关联引用片段，前端展示来源。
6. 用户选择知识点后，生成知识卡片、练习题或复习计划。

## 6. 错误处理
- 文件格式不支持：上传前提示支持的格式。
- 文件解析失败：保留失败状态，提供重试操作。
- 检索不到相关内容：返回“资料中未找到”，并给出改写问题建议。
- AI 服务超时或失败：自动重试一次；仍失败时保留用户输入并显示可重试状态。
- 没有可靠引用：标注“未验证”，不将推测内容伪装成资料结论。
- 重复上传同名文件：显示版本或时间信息，不覆盖已有文档。

## 7. 测试策略
1. 文档解析与分块单元测试。
2. 检索准确性、引用关联和无结果处理测试。
3. 后端接口集成测试。
4. 上传、问答、知识卡片、练习和计划的 UI 流程测试。
5. 回答是否引用正确来源的评估用例。
6. 桌面端和移动端关键页面的可用性检查。

## 8. 演示路径
1. 创建“数据结构”课程。
2. 上传讲义和历年试题。
3. 提问“二叉搜索树的查找复杂度是多少”。
4. 展示答案、原文引用和知识点卡片。
5. 生成一道练习题并作答。
6. 设置考试时间并生成复习计划。
