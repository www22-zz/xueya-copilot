# Agent P0：可信执行基础

用户已批准按升级方案实施，当前只交付 P0。保留主服务、HTTP/SSE、原学习功能及输入框附件/录音功能；P1 动态规划不在本次范围。

## 实施清单

1. 主聊天 direct/workflow 复用 C 的 finalize_answer；补强畸形 claims/source 输入，原文版本在发布前再次校验。未核验改写只能返回明确原文摘录。通用问答保留无课程证据标记。
2. 主 Provider 限制每次输出、检查 finish_reason/意外工具调用和流式完成边界。完整但不可用的响应与网络结果未知分开记账；不新增付费重试。
3. 用服务器端运行预算覆盖 HTTP 整个响应生命周期及后台作业。ContextVar 在子任务间共享额度，每次调用预留额度；取消、未知用量不返还不确定费用。默认限制模型次数、工具次数、累计输出和执行时间，可选文本费用上限。未配置计价或不支持计价的媒体调用在启用费用上限时拒绝发送。
4. 主聊天 MCP 会话显式限于四个兼容只读工具；服务器白名单不接受请求体或远端注解提升权限。原人工确认写入接口保留。
5. 添加离线回归：无依据内容、畸形/伪造 claims、过期资料、截断/异常结束、超限阻止发送、并发共用额度、取消与账本、工具越权及已有确认流程。
6. 执行 Python 全量、原前端和浏览器检查，记录结果与实际边界。所有 API 验证使用受控 transport，不读真实密钥。

## 预算边界

运行预算是请求或后台作业边界，跨作业的持久化预算在 P2 扩展，不能宣称当前已实现整个动态 Agent 生命周期。默认 10 次模型、12 次工具、32768 累计预留输出 token、每次最多4096 token、300秒；计数不等于费用。费用采用用户配置的当前文本模型输入/输出单价与保守输入估计预留；不是供应商账单保证。媒体计价未知时不得套用文本单价。已有媒体 maxCalls 和显式确认继续生效。

## 验收门槛

合法来源 ID 不能证明任意结论；截断响应不能成为 done；预算拒绝发生在网络发送之前；未知调用不自动重发；主聊天无法调用写入/外部工具；原确认、取消、课程隔离、接口字段保持。
