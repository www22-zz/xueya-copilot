# G5 多模态与复习音频设计

依据已确认的 ON-11/12 与 G5 整包任务实施，基线 main `5699b99`。前端保留原框架，新增独立媒体学习组件；后端 Python，复用 LearningHost/课程作用域、原件库、JobQueue、版本/CAS 和调用账本，不用本地模型。

采用现有服务的增量扩展，避免另建播客系统或依赖本地推理。WAV 由 Python 按实际采样边界分段；浏览器将可解码录音/音频转换为单声道 16k PCM WAV，视频使用浏览器按用户指定范围/数量抽帧。浏览器声明的帧时间标为客户端采样时间，不冒称逐字对齐或理解整段视频。普通文本仍走已有 B 资料导入。

音频原件最多一小时/120MB；每段请求不超过7MB，最多120段。视频原件最多50MB/30分钟，用户选择1～24帧及范围。原件存储上限只为媒体提高，既有文档上传限制保持。上传/分段免费，转写/图片分析/合成须显式确认并展示调用次数上限。业务任务分段持久化，停止/失败/重启保留已完成项；unknown只有人工核对后显式新任务，不自动收费重试。

转写先待核对，可逐段校正并保存新版本，显示真实片段定位；确认后的逐段文本可预览导入 B，连同原件/时间映射供 G2 阅读器跳回原件。视频结果保留实际采样帧和覆盖范围，可核对总结。

复习脚本支持单人/双人角色，基于当前资料、核对笔记或复习卡生成有出处的提纲、解释、易错条件、回忆问题、留白、答案和提示。第一版用确定性原文模板，不伪称未调用的模型创作；人工可编辑并逐段确认。保存版本后再明确确认 TTS。双角色可用供应商已有音色，不依赖克隆。

音频缓存绑定课程、配置、段落文本及音色；编辑一段只重合成变化段。保存实际 WAV 时长，提供分段播放/留白、字幕、脚本/音频下载与进度。听完不写掌握度；关联现有 FSRS 卡的用户明确自评才调用原复习接口，否则进入现有题库实际作答。

验证覆盖真实 WAV 边界/坏文件、幂等与版本、课程隔离、资料失效、配置漂移、单API许可、取消/unknown恢复、部分完成不重放、缓存增量、确认后导入、真实前端入口/刷新/移动端及既有227项后端/41项前端与浏览器回归。真实 API 效果须另有明确费用授权，本次仅受控上游。

实施顺序：领域音频/脚本工具→主平台队列与路由→前端上传/录音/抽帧/编辑/播放→专项和浏览器→全量回归→交付文档与PR。内部步骤由 AI 连续执行；不把实现整包任务变成反复请求人工审批。
