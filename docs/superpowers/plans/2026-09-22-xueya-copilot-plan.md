# 学涯 Copilot 实施计划

## 交付目标
交付一个可直接打开运行的响应式 Web 原型，完成课程知识库、AI 问答、引用查看、知识卡片、练习题和复习计划的核心流程。当前阶段使用确定性的演示数据模拟 AI 输出，接口层保持可替换。

## 文件结构
- `index.html`：应用入口和可访问的主布局。
- `styles.css`：设计令牌、响应式布局、组件样式和动效。
- `app.js`：课程、知识库、对话、引用、练习和计划状态。
- `docs/superpowers/specs/2026-09-22-xueya-copilot-design.md`：已确认设计规格。

## 实施步骤
1. 建立应用壳层、导航、课程切换和响应式布局。
2. 实现课程概览、知识库上传状态、文档列表和来源摘要。
3. 实现多轮问答工作区、模拟检索回答、引用面板和原文高亮。
4. 实现知识卡片、练习题和复习计划面板。
5. 补齐空状态、错误状态、键盘焦点、减少动效和移动端布局。
6. 使用浏览器运行并检查桌面端和移动端关键交互。

## 验收标准
- 打开 `index.html` 即可看到完整工作台。
- 点击提问示例或输入问题可得到带引用的演示回答。
- 可以打开引用来源、保存知识卡片、生成练习题和更新复习计划。
- 页面在窄屏下不出现文字溢出或控件重叠。
