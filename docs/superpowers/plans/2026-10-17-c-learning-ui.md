# C 前端接入实施顺序

设计已获用户确认，沿用现有学习空间。

1. 补齐同课程学习产物/任务/版本查询、候选题审核持久化、图谱、资料对照及媒体接口，沿用现有令牌、SQLite 与模型调用账本。
2. 添加浏览器学习服务及独立 UI 控制器，在现有页面内挂载业务区域。统一处理资料选择、忙碌/取消、预览/采纳和刷新恢复。
3. 接通学习包、题目审核/测验/订正、记忆卡/FSRS、计划/反馈、图谱和多模态校正。
4. 增加跨课程、版本冲突、过期资料、重复提交、媒体校正和端到端浏览器回归；完整运行原有检查。
5. 更新接入说明与实际使用说明，交付可检查的功能提交。

验证使用隔离数据库与受控上游，不消耗真实 API 费用。
