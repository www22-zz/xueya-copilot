# 个人资料库

> 功能名：个人资料库（知识库资料管理）。作用是上传并管理课程资料，完成解析、校正确认、向量索引后，为 AI 问答与知识点练习提供可追溯的原文依据。

## 功能名与作用

- 资料目录：列出当前课程的全部资料，显示格式、大小、章节、切片数、页数、解析状态、向量索引状态与是否可用于检索。
- 上传资料：支持 PDF、PPTX、DOCX、TXT、Markdown 多选批量上传；PDF ≤ 64 MB，PPTX/DOCX ≤ 10 MB，TXT/MD ≤ 1 MB；Office 临时文件（~$ 开头）会被跳过。
- 解析与校正：上传后自动解析正文；可在「校正与确认」中逐块对照原件修正文字，确认后的修订才用于检索。
- 向量索引：为当前资料建立向量索引，优先复用已有向量缓存；缺失片段需确认外部 API 调用。
- OCR 与图片补录：扫描版 PDF 可按页选择文字识别（每批最多 20 页）；PPTX 支持导入图片转写结果做「图片文字补录与空白核对」。
- 替换旧资料：可用新 PDF 替换旧 PPT，旧原件与历史保留，检索范围切换到新资料。
- 删除资料：删除资料会同时删除其向量索引（需二次确认）。
- 自动出题状态：与资料关联的题库生成任务状态显示在页面中，可跳转练习页继续。

## 所属模块

课程资料模块。前端 `frontend/js/knowledge-base.js`（挂载于 `#spaceContent` 的 `#knowledgeWorkspace`）；后端平台知识库接口 `backend/xueya/knowledge_base.py`、检索服务 `backend/xueya/rag_service.py`、OCR/向量服务 `backend/xueya/rag_http.py`。

## 进入路径

- 侧栏「个人资料库」→ `#space/knowledge`（页面顶部面包屑显示「课程资料学习 / 个人资料库」）。
- 资料学习页 `#space/materials` 的资料与知识点详情也会跳转到本页查看原文。
- 其他入口：概览「整理课程资料」、课程播放页「讲义资料」按钮。

## 操作步骤

1. 打开 `#space/knowledge`，点右上「资料上传」，选择一个或多个文件，核对文件列表与大小，可选「所属章节」，点「开始上传」。
2. 上传完成回到资料列表，等待解析任务完成（处理中会有进度条）；解析完点「校正与确认」，对照原件修改文字，勾选确认后保存。
3. 点「建立向量索引」：系统先给出片段数、可复用向量数、需计算数，勾选确认外部调用后提交；已有匹配缓存时不会重复计费。
4. 扫描版 PDF 若有待识别页，点「选择识别页」，输入页码或范围（≤20 页），确认后提交 OCR。
5. 资料确认且索引就绪后，点「用于问答」会把该资料设为当前问答的资料范围并跳到主问答；也可以在提问时选择资料范围。
6. 需要删除资料时点列表底部「删除」，确认后资料与其向量索引一起删除。

## 涉及路由

- 页面：`#space/knowledge`。
- 接口（平台知识库前缀 `/api/platform/knowledge`）：
  - `POST /knowledge/upload`：上传资料（可带幂等键）。
  - `GET /knowledge/catalog`：资料目录与统计。
  - `POST /knowledge/process`：提交解析 / 索引 / OCR 任务（需确认外部调用）。
  - `GET /knowledge/index-plan`：索引计划（片段数、可复用向量数）。
  - `POST /knowledge/review-confirm`：确认当前修订可用于检索。
  - `POST /knowledge/visual-preview`、`/knowledge/visual-apply`：图片补录预览与应用。
  - `POST /knowledge/remove`：删除资料与索引。
- 相关：`/api/platform/rag/search`（检索）、`/api/platform/rag/read`（读取原文）。

## 常见问题

- 问：为什么上传后不能马上提问？答：资料需要先解析并「确认」当前修订，建立索引后才会被检索；未确认的修订不计入检索范围。
- 问：向量服务未配置会怎样？答：仍可使用关键词检索；页面会提示在环境配置中设置 `RAG_EMBEDDING_*` 后重启服务。
- 问：OCR 为什么只允许 20 页一批？答：每批限制是为了控制单次外部调用体积与费用；可分批提交，已完成结果会复用。
- 问：校正后原来的向量还能用吗？答：校正会产生新修订，旧向量失效，需要重新建立索引。
- 问：页面上没有资料检索输入框？答：当前版本资料检索由主问答（课程资料 RAG）完成，资料库页面专注于上传、确认与索引管理。
- 问：能直接看 PDF 原件吗？答：可以，资料行「查看原文」可读抽取正文；「下载原件」可保存原始文件。
