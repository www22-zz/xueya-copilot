# 页面与路由目录

> 前端使用 hash 路由：`#space/{视图}/{参数…}`。本页列出实际存在的页面、参数、渲染入口与重定向规则，按 `frontend/js/app.js` 的真实代码整理。

## 功能名与作用

路由目录用于定位「某个页面到底对应哪个哈希地址、由哪个 JS 文件渲染、是否还有子页面参数」。排查导航问题或给功能做收藏/分享链接时先查这里。

## 所属模块

前端路由层（`frontend/js/app.js`）+ 各视图 JS 模块。

## 进入路径

- 学习空间统一前缀：`#space/`。
- 首页产品介绍：`#home`；首页锚点：`#possibilities`、`#evidence`、`#rhythm`。

## 操作步骤

1. 在地址栏把 `#space/xxx` 替换为下表中的地址即可直达页面。
2. 带参数的页面（如 408 试卷、我的小测）先进入列表页再点击，地址会由页面自动写入。
3. 遇到 404 或空白视图，先检查是否拼错：不存在的视图会显示 AI 助手页。

## 常见问题

- 问：为什么 `#space/graph` 打不开？答：当前版本没有独立的 graph 视图；课程知识图谱在 `#space/materials` 的「课程书架与知识图谱」标签内。
- 问：为什么刷新后回到 AI 助手？答：说明视图名不在 `titles` 注册表里，常见于手输错误或旧版链接。
- 问：408 试卷链接能不能直接发给别人？答：可以，试卷地址形如 `#space/exams/{试卷ID}`，但需要登录同一账号且本机服务可用。
- 问：`#space/practice/hot100` 和 `#space/algorithms` 有什么区别？答：后者只是兼容旧地址的重定向，最终都会落到 Hot100 工作台。

## 代码依据

- 路由解析与重定向：`frontend/js/app.js` 第 157 行 `route()`。
- 视图标题与渲染函数：`frontend/js/app.js` 中 `titles.*` / `renders.*` 赋值；`frontend/js/ui/views.js` 与 `frontend/js/ui/workspace-views.js`。
- 子路由参数解析：`app.js` 的 `render()` 中 `location.hash.split('/')`。
