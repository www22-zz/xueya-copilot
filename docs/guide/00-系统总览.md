# 学涯 Copilot 系统总览

> 一句话定位：学涯 Copilot 是一个运行在本机的「AI 伴学工作台」，把课程资料、视频课程、算法刷题、408 备考、学习计划和学情分析放在同一个本地学习空间里。

## 功能名与作用

系统主要面向个人长期学习：用户可以上传自己的讲义和笔记，让 AI 基于原文回答问题并给出来源；可以练习内置的算法与 408 题库；可以让 AI 制定学习计划、生成知识框架、写学情分析；右下角还有一只能对话的桌宠「小涯」。

所有 AI 推理都调用外部 API（不训练、不在本地跑模型），密钥只保存在本机环境配置中，页面和接口不会回传密钥内容。

## 所属模块

- 前端：原生 HTML / CSS / JavaScript（无构建步骤），入口 `frontend/index.html`，按 `frontend/js/*.js` 拆分模块。
- 后端：Python 3.13 + FastAPI，主程序 `backend/xueya/server.py`，路由装配在 `backend/xueya/app.py`。
- 数据：默认落在本机 `.xueya-data/` 目录（SQLite 数据库 `workspace.sqlite` 与 `files/` 原件），修改数据目录可用环境变量 `XUEYA_DATA_DIR`。
- 模型：文本问答走 MiMo 兼容接口（`MIMO_*` 配置）；课程资料向量化走 Qwen3-VL-Embedding（`RAG_EMBEDDING_*` 配置）。

## 进入路径

- 首页（产品介绍页）：`http://127.0.0.1:4173/`，顶部按钮「开始学习」进入 `#space/overview`。
- 学习空间：`#space/overview`（工作台概览），左侧固定侧栏提供各学习中心入口。
- 全局对话：`#space/ask`（AI 伴学助手）。
- 学习中心：课程资料学习 `#space/materials`、算法学习 `#space/practice/hot100`、408 考研学习 `#space/exams`、错题本 `#space/review`、个人资料库 `#space/knowledge`。
- 课程学习中心（视频课）：`#space/courses`。
- AI 学习分析：`#space/analysis`；我的学习计划：`#space/analysis/plans`。
- 桌宠小涯：任意学习页右下角的小机器人，点击「小涯」或机器人本体展开对话。

## 操作步骤

1. 启动本机服务：在仓库根目录运行 `.venv\Scripts\python.exe -m backend.xueya.server`（Windows 也可用 `一键启动学涯.cmd`），浏览器打开 `http://127.0.0.1:4173`。
2. 首次使用可点击右上角「开始学习」进入 `#space/overview`，在概览卡片里直接提问或进入各模块。
3. 在「个人资料库」上传资料并完成解析/确认后，主问答与知识点练习才能引用这些资料。
4. 学习过程中产生的对话、练习状态、计划、分析报告都由本机服务保存；页面刷新不会丢。
5. 想了解某个功能怎么做，可直接问右下角小涯：它能检索本系统百科并给出准确入口路径。

## 涉及路由（页面与接口）

| 类型 | 路径 | 说明 |
| --- | --- | --- |
| 页面 | `#home` | 产品介绍首页，含「开始学习」入口 |
| 页面 | `#space/overview` | 工作台概览（欢迎语、快捷提问、四大板块入口） |
| 页面 | `#space/ask` | AI 伴学助手主问答 |
| 接口 | `GET /api/health` | 服务健康检查与引擎状态 |
| 接口 | `POST /api/account/*` | 本地账号注册/登录/登出（可选） |
| 接口 | `GET /api/platform/bootstrap` | 前端启动引导（令牌、课程、工作区） |

## 常见问题

- 问：打开页面提示「本地模式」或「回答未完成」？答：说明当前服务没有配置可用的模型密钥，或外部模型暂时不可用；系统功能页仍可浏览，问答会退化为本地流程。
- 问：资料和记录保存在哪里？答：默认在仓库根目录的 `.xueya-data`，不要手工删除其中的 `workspace.sqlite` 和 `files`。
- 问：可以多人共用吗？答：默认是单机单用户；如需区分多人，可在系统设置「账号管理」里启用本地账号。
- 问：页面数据会不会上传到云端？答：只有 AI 问答、向量化、学情分析等需要调用外部 API 的操作会发送必要文本，前端不会上传本机密钥。

## 代码依据

- 前端路由与视图分发：`frontend/js/app.js` 的 `route()` 与 `render()`，视图标题在 `titles` 中注册。
- 首页与整体骨架：`frontend/index.html`。
- 后端装配：`backend/xueya/app.py` 的 `create_app()`；启动入口 `backend/xueya/server.py`。
- 配置读取：`backend/xueya/config.py` 的 `load_config()`。
- 平台数据层：`backend/xueya/platform.py`（Repository / FileStore / JobQueue）。
