# 桌宠小涯：系统专业 AI 助手

> 功能名：桌宠「小涯」（系统助手）。作用有两个：日常陪学聊天与今日学习提醒；回答「这个功能在哪里、怎么用」这类系统使用问题时，会先检索系统使用百科，再给出准确入口和操作步骤。

## 功能名与作用

- 悬浮桌宠：每个学习页面右下角都有小机器人，可拖动位置；点击机器人或「小涯」按钮展开对话面板；「−」收起为悬浮按钮；「✦」打招呼。
- 聊一聊：输入问题发送，支持多轮历史；回答中可以「停止」。
- 今日学习：面板第二个标签读取当前执行计划，显示今日任务、完成数量与预计分钟；有任务时可直接「开始今日学习」，没有计划时引导去定制计划。
- 系统使用问答：询问某个功能在哪个页面、该怎么操作这类系统使用问题时，小涯会：
  1. 检索系统使用百科（`materials/system-guide/` 的向量索引）；
  2. 找到相关功能文档片段，把功能名、页面路径、操作步骤放进上下文；
  3. 由模型基于这些片段回答，并在下方给出可点击的页面按钮；
  4. 系统里没有的功能会明确说「没有」，不编造入口。
- 普通聊天：与技术问题无关的闲聊或一般知识问题走通用问答，不影响系统使用问答。
- 降级：向量服务不可用时自动改用关键词检索；模型不可用时用检索到的百科片段拼出确定性操作说明（标注为本地指南），并说明当前模型不可用。
- 接口：`POST /api/learning/space/companion/chat`，请求 `{question, history, courseId}`，响应包含 `reply.status`（ok / not_found / unavailable）、`reply.route`（system / general）、`reply.answer`、`reply.sources`、`reply.links`。
- 索引检查接口：`GET /api/learning/space/companion/guide` 返回系统百科索引元数据（是否加载、chunk 数、模型、维度、构建时间），不触发向量调用，用于排查索引问题。

## 所属模块

AI 伴学模块 · 系统助手子模块。前端 `frontend/js/study-companion.js`（挂载在 `frontend/js/app.js`）；后端 `backend/xueya/companion_api.py`（对话接口）与 `backend/xueya/companion_knowledge.py`（系统百科检索）；知识来源 `docs/guide/` 与向量 `materials/system-guide/`。

## 进入路径

- 任意学习页右下角的小机器人 → 点「小涯」或机器人本体打开面板。
- 面板默认「聊一聊」标签；切「今日学习」查看今日任务。
- 也可以直接在面板里问「小涯你能做什么」。

## 操作步骤

1. 点击右下角小机器人，展开小涯对话面板。
2. 在输入框输入问题，Enter 发送、Shift+Enter 换行；点「发送」后等待回答，长回答可点「停止」中止。
3. 问系统功能时，回答下方会出现可点击的页面按钮（如「算法学习」「个人资料库」），点按钮直接跳转到对应页面。
4. 需要看今天学什么时，切到「今日学习」标签；有执行中计划会显示今日任务与完成进度，点「开始今日学习」进入计划路线。
5. 回答失败时按提示检查服务设置；系统类问题即使模型不可用也会返回检索到的操作说明。

## 涉及路由

- 页面：任意学习页（桌宠全局挂载）；快捷跳转使用真实 hash 路由：`#space/overview`、`#space/ask`、`#space/materials`、`#space/practice/hot100`、`#space/exams`、`#space/review`、`#space/knowledge` 等。
- 接口：`POST /api/learning/space/companion/chat`、`GET /api/learning/space/companion/guide`；今日学习使用 `GET /api/learning/space/plan/list`。
- 检索隔离：系统百科向量位于 `materials/system-guide/`，不写入用户课程向量表，也不会检索课程资料。

## 常见问题

- 问：小涯会看到我的课程资料吗？答：不会。系统助手的检索库是系统使用百科（`materials/system-guide/`），与课程资料 RAG 隔离；普通聊天不会附带课程原文。
- 问：为什么回答里说「系统百科暂未收录」？答：说明问题在当前系统文档中找不到对应功能，小涯会明确说明不存在或建议换一种问法，不会编造入口。
- 问：小涯回答很慢或失败？答：系统问题需要一次向量检索与一次模型调用；模型不可用时会自动降级成本地指南回答，失败不会自动重试。
- 问：为什么跳转按钮没有反应？答：按钮只会跳转到系统真实存在的页面；若页面被权限或服务状态限制，会停留在原页面并提示。
- 问：桌宠位置能改吗？答：可以拖动机器人调整位置，位置会记住；手机窄屏下会自动限制在可视区域内。

## 代码依据

- 前端：`frontend/js/study-companion.js`（面板、发送、渲染 links 与来源）；挂载点 `frontend/js/app.js` 中 `window.XueyaStudyCompanion?.mount(...)`。
- 后端：`backend/xueya/companion_api.py` 的 `install_companion(app)` 与对话路由；`backend/xueya/companion_knowledge.py` 的加载、混合检索与降级逻辑。
- 向量构建：`scripts/build_system_guide_vectors.py`；产物 `materials/system-guide/manifest.json` 与 `vectors.json`。
- 文档来源：`docs/guide/*.md`（本目录）。
