# 算法学习与 Hot100 刷题

> 功能名：算法学习（力扣 Hot100 精选题库）。作用是把 100 道经典算法题按 17 个官方专题组织起来，支持筛选、写代码、真实运行、查看题解、AI 分析、记录掌握状态与错题。

## 功能名与作用

- Hot100 题库：100 道算法题，按力扣官方 17 个专题（哈希、双指针、滑动窗口、子串、普通数组、矩阵、链表、二叉树、图论、回溯、二分查找、栈、堆、贪心算法、动态规划、多维动态规划、技巧）分组。
- 知识点导航：按该题官方专题（当前数据为 17 个官方专题）生成导航按钮并显示每个知识点的题目数量；「全部知识点」视图按专题分组列出题目，筛选后选中题会滚入可视区。
- 题目筛选：搜索题号/题名/关键词，筛选难度、标签与状态（待刷 / 已掌握 / 错题本），一键随机刷题。
- 代码练习：题目详情提供代码编辑器（Python / C++ / Java 等可用语言）。首次打开题目时编辑器显示可写的初始代码骨架（类/方法签名与参数，不含核心实现）；已保存的草稿优先，不会被覆盖。可以「运行代码」用题库样例真实执行比对，「AI 分析」给出复杂度与风险提示，也有完整题解与易错点。
- 编辑器工具：工具栏可切换语言、「重置为初始骨架」、代码格式化与快捷键提示；同一题目同一语言同一份代码的 AI 分析会复用缓存。
- 静态题（填空/单选/简答）：按题型作答、揭示参考解答、标记掌握度。
- 状态与错题：每道题可标记「已掌握 / 待巩固 / 加入错题本 / 已攻克 / 移回待刷」，状态保存在本机服务，离线时进本地队列稍后同步。
- 交互演示：题目详情可打开独立的算法交互实验室页面（`/algorithm-demo.html?question={题目ID}`），逐步观察数据结构、指针与状态变化，支持播放/暂停/重置/调速。是否可用由后端演示注册表决定（`frontend/js/algorithm-demo-registry.js`，由脚本从后端可演示题目生成）；没有演示数据的题目不显示该入口。
- 随手记：每题可写笔记并预览，冲突时保留服务端与本地两个版本供选择。

## 所属模块

算法学习模块。前端 `frontend/js/practice-view.js`（列表与详情）、`frontend/js/practice-hub.js`（练习首页）、`frontend/js/services/practice-client.js`（题库与状态同步）；后端 `backend/xueya/practice_api.py`、`backend/xueya/practice_catalog.py`、`backend/xueya/code_runner.py`。

## 进入路径

- 侧栏「算法学习」→ `#space/practice/hot100`（旧地址 `#space/algorithms` 自动重定向到这里）。
- 概览「专项练习与题库」卡片 → `#space/practice`，再选「先练算法 Hot100」。
- 练习首页：`#space/practice`。
- 算法交互演示独立页：`/algorithm-demo.html?question={题目ID}`（从题目详情「打开交互演示」按钮打开）。
- 旧地址 `#space/algorithms` 会自动重定向到 `#space/practice/hot100`；页面不提供单独的「返回算法学习」按钮，浏览器返回即可。

## 操作步骤

1. 打开 `#space/practice/hot100`，顶部状态按钮可切换「待刷 / 已掌握 / 错题本」计数视图，搜索框支持题号、题名、关键词。
2. 左侧知识点导航选择专题（显示官方专题数量与各专题题数），或留在「全部知识点」按专题分组浏览；题目列表选择一道题，也可点「随机刷题」。
3. 在题目详情阅读题目描述与示例，切到「代码」标签：编辑器已预填可写的初始骨架，直接补充实现即可；选择语言后点「运行代码」会真实执行题库样例并逐条显示输入、预期、实际。
4. 需要思路时点「AI 分析」查看时间/空间复杂度与风险点（会调用外部模型）；点「查看完整题解」查看参考实现与易错点。
5. 做完后点「已掌握」或「加入错题本」，需要二刷时点「待巩固」；状态会立即记入本机并同步服务端。
6. 在「随手记」记录易错点；写到一半离开不会丢，保存失败会提示并保留草稿。
7. 想逐帧理解算法时，在题目详情点「打开交互演示」跳转独立实验室页面；页面会播放后端返回的确定性教学步骤，演示失败会明确报错而不是伪造步骤。

## 涉及路由

- 页面：`#space/practice/hot100`（旧 `#space/algorithms` 重定向）、`#space/practice`、`/algorithm-demo.html?question={id}`。
- 接口：
  - `GET /api/practice/bank?source=workspace`：读取固定题库（Hot100 100 + 408 300）。
  - `GET /api/practice/state`、`POST /api/practice/ops`：同步作答状态、笔记与状态操作。
  - `GET /api/practice/notes/{questionId}`：读取题目笔记。
  - `POST /api/learning/space/workbench/code/run`：运行用户代码（本机子进程，带超时与输出上限）。
  - `POST /api/learning/space/workbench/code/analyze`：AI 代码复杂度分析。
  - `POST /api/learning/space/quiz/fixed-attempt`：提交固定题作答并生成评阅。
  - `GET /api/learning/space/algorithm-demo/{questionId}?sample=N`：读取交互演示步骤。

## 常见问题

- 问：为什么「运行代码」提示不支持当前语言？答：本机没有检测到对应的编译器/解释器；可在题目里切换语言或点「重新检测」，仍可查看官方题解。
- 问：题目状态在换设备后还在吗？答：状态保存在本机服务的账号下；离线时先写浏览器本地队列，联网后再同步。
- 问：AI 分析会计费吗？答：会调用已配置的外部模型，属于付费调用；失败不会自动重试。
- 问：知识点导航里的专题与题目对不上？答：专题来自官方 Hot100 数据（`hot100_official.json`），100 道题每题都有 topic 与 tags；导航按官方专题生成并显示计数，筛选后列表会显示对应专题的题目。
- 问：交互演示覆盖所有题吗？答：以 `frontend/js/algorithm-demo-registry.js` 中的注册表为准（当前覆盖 Hot100 100 题）；注册表由后端可演示题目导出，没导出的题目不显示「交互演示」入口。
- 问：首次打开的代码是答案吗？答：不是。初始内容是题目要求的代码骨架（类/方法签名/参数），核心实现需要自己补；用户已保存的代码与草稿优先，点「重置为初始骨架」可恢复。
- 问：错题本为什么没有某道题？答：「错题本」按最近一次有效判定归集，只有标记错误/加入错题本的题会出现。
