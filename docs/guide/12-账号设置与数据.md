# 账号、设置与数据

> 功能名：本地账号与系统设置。作用是管理学习空间账号、外观主题、服务连接与后台任务，并说明数据保存、导出与备份的位置。

## 功能名与作用

- 本地账号（可选）：首次使用是单机本地空间，无需登录；在「系统设置 → 账号管理」启用团队账号后，下次打开需要登录，资料与学习记录按账号隔离。
- 登录 / 注册 / 修改密码 / 退出登录：登录弹窗支持注册与登录切换；账号 3–40 位字母数字点横线下划线，注册密码 8–16 位并含字母和数字。
- 系统设置弹窗：三个标签——通用设置（外观：浅色 / 深色 / 跟随系统）、账号管理、服务与数据。
- 服务与数据：服务设置与任务中心，可查看「服务与能力」（配置、连接验证分开记录，免费检查不调用模型）、「任务与用量」（后台任务、取消任务、实际 API 用量、待确认与待处理）。
- 数据导出：顶部「导出记录」按钮下载当前学习记录 JSON（文件名为「学涯学习记录-日期.json」）。
- 数据保存位置：默认 `.xueya-data/workspace.sqlite`（业务数据）与 `.xueya-data/files`（原件），页面 UI 状态与离线队列保存在浏览器本地存储。
- 全局搜索/统一搜索：顶部搜索按钮（Ctrl/⌘+K）打开「内容搜索与综合问答」，可搜索当前课程与当前会话内容；该入口也会出现在设置的服务面板中。

## 所属模块

系统模块。前端 `frontend/js/account.js`（账号与登录门禁）、`frontend/js/preferences.js`（系统设置弹窗与主题）、`frontend/js/workbench-ui.js`（服务与任务中心）、`frontend/js/search-workspace.js`（内容搜索与综合问答）、`frontend/js/workspace-controller.js`（导出）；后端 `backend/xueya/account.py`、`backend/xueya/workbench_http.py`。

## 进入路径

- 系统设置：右上角齿轮按钮、头像/「我的账号」、侧栏底部「系统设置」、设置悬浮按钮（右下角 ⚙ 设置）。
- 账号管理：系统设置弹窗 →「账号管理」。
- 服务与数据：系统设置弹窗 →「服务与数据」。
- 登录/注册弹窗：启用账号后访问 `#space/*` 会自动弹出登录门禁。
- 导出记录：顶部工具栏「导出记录」按钮。

## 操作步骤

1. 切换主题：打开系统设置 →「通用设置」→ 点浅色 / 深色 / 跟随系统，立即生效并记住选择。
2. 启用团队账号：系统设置 →「账号管理」→ 输入账号与密码 →「启用团队账号」；下次打开需要登录。已启用时可在此修改密码或退出登录。
3. 查看服务与能力：系统设置 →「服务与数据」→「服务与能力」，查看各服务是否配置；免费检查只做本地配置检查，不调用模型。
4. 查看任务与用量：切到「任务与用量」，查看后台任务状态、实际 API 调用记录与待确认项；可取消任务，但结果不明的请求不会自动重试。
5. 导出数据：点顶部「导出记录」下载 JSON 备份；需要完整迁移时同时复制 `.xueya-data` 目录。
6. 全局搜索：按 Ctrl/⌘+K 或点顶部搜索框，输入关键词后检索课程内容与对话。

## 涉及路由

- 页面：`#home`（未登录访问会先显示登录弹窗）、`#space/*`（登录门禁）。
- 接口：
  - `GET /api/account/status`：账号状态（是否已配置、是否登录、用户名）。
  - `POST /api/account/setup`、`/register`、`/login`、`/logout`、`/password`：账号操作。
  - `GET /api/platform/workbench/capabilities`：服务与能力。
  - `GET /api/platform/workbench/tasks`：任务与用量。
  - `GET /api/platform/bootstrap`：前端引导数据与令牌。
  - `GET /api/health`：服务与引擎状态。

## 常见问题

- 问：忘记账号密码怎么办？答：本机单用户场景可联系维护者直接处理本机 `.xueya-data`；系统不提供邮箱找回。
- 问：换电脑怎么迁移？答：复制整个 `.xueya-data` 目录，并保证 `.env` 中的模型配置可用；也可用「导出记录」导出学习记录 JSON 备份。
- 问：密钥配置在哪里改？答：本机仓库根目录 `.env`（模型/向量服务等），修改后重启服务；密钥不会展示在前端页面。
- 问：「服务与能力」显示已配置是否代表能用？答：已配置只代表本机读到了配置；连接验证与真实调用需要另外执行，页面不会自动付费测试。
- 问：清除浏览器数据会丢什么？答：会丢本机界面的临时状态（草稿、离线队列等），服务端保存的资料与记录仍在；重新登录后可恢复。
- 问：为什么打开页面就要求登录？答：说明此前在「账号管理」中启用了团队账号，输入账号密码即可进入。

- 设置与主题：`frontend/js/preferences.js` 的 `mount()`、`applyTheme()`。
- 服务与任务：`frontend/js/workbench-ui.js`；后端 `backend/xueya/workbench_http.py`。
- 导出：`frontend/js/workspace-controller.js` 的 `exportWorkspace`。
