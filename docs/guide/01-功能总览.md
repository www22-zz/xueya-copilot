# 功能总览：学涯 Copilot 能做什么

> 本页按模块列出全部主要功能与真实入口，用来快速判断「某个需求应该去哪一页」。所有入口均以当前前端路由为准。

## 功能名与作用

学涯 Copilot 的功能分为六组：AI 问答伴学、课程与资料、算法与题库、408 备考、学习计划与分析、账号与数据。每组都有独立的页面路由和后端接口，互不覆盖数据。

## 所属模块

- 「AI 伴学」组：主问答 `#space/ask`、桌宠小涯、视频随堂问答、全局内容搜索。
- 「学习中心」组：课程学习中心 `#space/courses`、课程资料学习 `#space/materials`、个人资料库 `#space/knowledge`。
- 「题库」组：练习首页 `#space/practice`、算法 Hot100 `#space/practice/hot100`、408 题库 `#space/practice/exam408`、我的小测 `#space/practice/ai`、错题本 `#space/review`。
- 「408」组：408 考研学习工作台 `#space/exams`、模拟考试 `#space/exams/{试卷ID}`。
- 「计划与分析」组：AI 学习分析 `#space/analysis`、我的计划 `#space/analysis/plans`、个性化学习计划 `#space/materials/plan`、知识框架 `#space/frameworks/{id}`。
- 「系统」组：系统设置（右上角齿轮）、本地账号、数据导出、服务与任务中心。

## 进入路径

| 想做的事 | 入口 |
| --- | --- |
| 问一道课程问题 / 让 AI 讲解 | `#space/ask`（侧栏顶部「AI 伴学助手」） |
| 从概览页直接提问 | `#space/overview` 的 AI 伴学助手卡片输入框与快捷问题 |
| 上传讲义、笔记、PDF | `#space/knowledge`「资料上传」 |
| 看课程视频、随堂问 AI | `#space/courses` |
| 按资料知识点学、看课程书架图谱 | `#space/materials` |

| 刷 408 题库 | `#space/practice/exam408` 或 `#space/exams` |
| 做模拟考试 | `#space/exams` →「设置并开始模拟」 |
| 复习错过的问题 | `#space/review`（侧栏「错题本」） |

| 问系统功能在哪 | 右下角小涯，或直接问系统助手 |

## 操作步骤

1. 先明确任务属于哪一组：问知识 → AI 伴学；找资料 → 个人资料库；刷题 → 练习；备考 → 408；安排节奏 → 计划与分析。
2. 使用左侧栏「学习中心」五个固定入口，或在概览页四大板块卡片进入。
3. 页面顶部的全局搜索按钮（快捷键 Ctrl/⌘+K）打开「内容搜索与综合问答」，可检索当前课程与当前会话的内容。
4. 想找某个功能的位置时，直接问桌宠小涯（例如「错题本在哪里」），它会返回可点击的页面按钮。

## 涉及路由

- 页面路由全部写在 `frontend/js/app.js` 的 `route()`：`#space/{view}/{param1}/{param2}`。
- 主要视图：overview、ask、courses、materials、practice、review、exams、knowledge、analysis、frameworks、media。
- 打开一个不存在的视图时，前端会回退到 `#space/ask`。
- `#space/algorithms` 会被自动重定向为 `#space/practice/hot100`；`#space/library` 会被重定向为 `#space/knowledge`。

## 常见问题

- 问：为什么点侧栏「课程资料学习」和概览里的「学习中心」看起来不一样？答：侧栏进入的是资料学习工作台（`#space/materials`），概览卡片里的「课程学习中心」进入视频课程页（`#space/courses`），两者是不同模块。
- 问：某些功能没有侧栏入口？答：知识框架历史、录音与视频工具等页面需要通过地址栏或页面内链接进入，详见「功能限制与未实现」。
- 问：页面标题与侧栏名称不一致？答：视图内部会有自己的大标题，浏览器标签页标题使用 `titles[view]`。

## 代码依据

- 视图注册：`frontend/js/app.js` 顶部 `titles`/`renders` 赋值；`frontend/js/workspace-controller.js` 的 `enhance()`。
- 侧栏：`frontend/index.html` 的 `#stitchSidebar` 与 `.learning-center-nav`。
- 模块挂载：`frontend/js/app.js` 的 `render()` 按 `state.view` 调用各模块 UI。
