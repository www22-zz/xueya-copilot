# 课程学习中心（视频课程）

> 功能名：课程学习中心 / 视频课程工作台。作用是把预置的计算机体系视频课和用户自己添加的视频课程放在一起，支持站内播放、标记学完、随堂追问 AI。

## 功能名与作用

- 视频课程目录：按分类（全部体系课程、计算机考研 408、数据结构与算法、操作系统与网络、AI 与智能体前沿）浏览课程，支持关键词搜索。
- 课程播放页：在站内播放 B 站官方嵌入课程，或切换 HTML5 播放器播放本地视频文件。
- 随堂 AI 问答：播放页右侧/下方的随堂对话区可以围绕当前分集向 AI 提问，回答带课程资料来源。
- 学习进度：手动「标记已学完」后写入服务端进度，并同步到学习计划里的课程任务；播放位置会记录，但播放位置不等于掌握。
- 自定义课程：可以添加自己的私人视频课（名称、分类、难度、讲师、播放源、简介），在「管理课程」中删除。

## 所属模块

课程学习模块。前端 `frontend/js/courses-workspace.js`；后端接口在 `backend/xueya/study_space_api.py` 与 `backend/xueya/course_records.py`。

## 进入路径

- 侧栏或概览卡片：「学习中心核心板块」卡片「课程学习中心」→ `#space/courses`。
- 概览顶部「课程与学习记录」胶囊 → `#space/courses`。
- 课程资料学习页的「视频目录」标签 → `#space/materials/video`（嵌入式课程目录）。
- 具体课程播放页：`#space/courses/{课程ID}/{分集ID}`，课程 ID 例如 `cs-ds-algo`、`mooc-os`。

## 操作步骤

1. 打开 `#space/courses`，在分类标签与搜索框中找到课程，点击课程卡片进入播放页。
2. 播放页上方有「返回目录」「标记已学完 / 已学完」「讲义资料」「原站课程页」「随堂练习」按钮。
3. 在「视频播放源」条切换「B 站在线高清播放器」或「本地无损 / HTML5 播放器」；也可以点「选取本地视频文件」用本机视频替代在线源。
4. 观看后在随堂对话输入问题，点发送；回答生成中可点「停止生成」，失败可点重试。
5. 学完一节后点「标记已学完」，完成状态会保存到本机服务并同步学习计划。
6. 想添加自己的课程：目录页点「添加自定义视频课」，填写表单后「确认添加并开始学习」。

## 涉及路由

- 页面：`#space/courses`（目录）、`#space/courses/{courseId}/{episodeId}`（播放）。
- 接口：
  - `GET /api/learning/space/courses`：读取预置课程、私人课程与学习进度。
  - `POST /api/learning/space/courses/save`：保存自定义课程。
  - `POST /api/learning/space/courses/progress`：记录完成状态与播放位置。
  - `POST /api/learning/space/courses/delete`：删除本人私人课程。
  - `POST /api/agent/stream`：随堂 AI 追问（与主问答共用流式接口）。
  - `POST /api/learning/space/plan/sync-course`：课程完成同步到学习计划。

## 常见问题

- 问：视频显示「B 站官方嵌入 · 站内可播」但打不开？答：B 站嵌入需要联网，且受浏览器第三方播放限制影响；可尝试切换「本地无损 / HTML5 播放器」或用「选取本地视频文件」。
- 问：本地视频会上传吗？答：不会，本地视频只通过浏览器 Object URL 播放，不上传服务端。
- 问：「标记已学完」算掌握了吗？答：不算，它只是课程任务完成标记；掌握度来自题库作答与复习记录。
- 问：为什么我的自定义课程在刷新后还在？答：课程与进度保存到本机 `.xueya-data` 的服务端记录里，换账号时按账号隔离。
- 问：随堂 AI 提示无法生成？答：随堂问答依赖已配置的模型服务；未配置时会提示改用完整对话台。

## 代码依据

- 课程目录与播放器：`frontend/js/courses-workspace.js` 的 `renderCatalog()`、`renderPlayer()`、`askInClass()`、`mount()`。
- 预置课程数据：`frontend/data/video-courses.json`（服务端 `platform_courses()` 读取同一文件）。
- 后端课程记录：`backend/xueya/course_records.py` 的 `listing()`、`record()`、`save_course()`。
- 接口注册：`backend/xueya/study_space_api.py` 中 `/courses`、`/courses/save`、`/courses/progress`、`/courses/delete`。
