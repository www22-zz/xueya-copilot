# 练习与错题本

> 功能名：练习空间与错题本。作用是把「题库刷题、我的小测、错题复习、随手记」放在统一入口，按算法、课程资料、408 三类来源分别记录状态。

## 功能名与作用

- 练习首页 `#space/practice`：展示算法 Hot100、我的小测与作答、408 考研题库、错题复习四个入口卡片。
- 题库分类：
  - `#space/practice/hot100`：力扣 Hot100 100 题（详见「算法学习与 Hot100」）。
  - `#space/practice/exam408`：408 固定题库（240 单选 + 60 综合应用）。
  - `#space/practice/foundation`：旧基础题（基础 100 题保留）。
  - `#space/practice/interview`：旧面试题（面试 50 题保留）。
  - `#space/practice/legacy`：与课程资料关联的固定练习（旧题与记录保留）。
  - `#space/practice/ai`：我的小测与作答列表；`#space/practice/ai/{题目ID}`、`#space/practice/ai/{题目ID}/{作答ID}` 查看具体题目与历史作答。
- 我的小测：可在主问答中主动请求小测，或在题目页生成；保留原答案、AI 参考评阅、复核与人工修正，题目仅本人可见。
- 错题本 `#space/review`：按「资料错题 / 算法错题 / 考研错题」三类归集，支持「最近出错优先」「错误次数最多」排序，可一键重练。
- 随手记：每道题都能写笔记，支持预览；保存冲突时保留双版本供选择。
- 作答状态：待刷 / 已掌握 / 待巩固 / 错题 / 已攻克；离线操作先写本地队列，联网后同步。

## 所属模块

题库练习模块。前端 `frontend/js/practice-hub.js`、`frontend/js/practice-view.js`、`frontend/js/study-quiz.js`；后端 `backend/xueya/practice_api.py`、`backend/xueya/practice_catalog.py`、`backend/xueya/object_questions.py`。

## 进入路径

- 练习首页：概览「专项练习与题库」→ `#space/practice`；或直接访问 `#space/practice`。
- 错题本：侧栏「错题本」→ `#space/review`；分类子路由 `#space/review/materials`、`#space/review/algorithms`、`#space/review/exams`。
- 我的小测：`#space/practice/ai`。
- 旧题入口：`#space/practice/foundation`、`#space/practice/interview`、`#space/practice/legacy`。

## 操作步骤

1. 打开 `#space/practice`，按目标选择卡片：刷算法、练 408、做小测、复习错题。
2. 在题目列表选择题目，按题型作答：单选/多选选择选项提交；填空输入文本提交；代码题写代码后运行；综合题按小问作答并自评。
3. 作答后标记状态（已掌握 / 待巩固 / 加入错题本）；答错的题会自动进入错题本对应分类。
4. 打开 `#space/review`，选错题分类，点错题可直接重练；答对后可点「已攻克」或「移回待刷」。
5. 我的小测里可以查看每次作答的原始答案、AI 评阅与人工修正记录；争议可提交复核。
6. 需要整理思路时用「随手记」写笔记，支持 Markdown 预览。

## 涉及路由

- 页面：`#space/practice`、`#space/practice/{hot100|exam408|foundation|interview|legacy|ai}`、`#space/practice/ai/{题目ID}/{作答ID}`、`#space/review`、`#space/review/{materials|algorithms|exams}`。
- 接口：

  - `GET /api/practice/state`、`POST /api/practice/ops`：状态、笔记、作答同步。
  - `GET /api/practice/notes/{questionId}`：题目笔记。
  - `POST /api/practice/analysis`：提交练习分析任务；`GET /api/practice/analysis` 读取报告列表。
  - `POST /api/learning/space/quiz/fixed-attempt`：固定题作答与评阅。
  - `GET /api/learning/space/quiz/list`、`GET /api/learning/space/quiz/attempts/{attemptId}`：我的小测与作答明细。

## 常见问题

- 问：为什么「错题本」里题目数量与「错误次数」对不上？答：错题本按每题最近一次有效判定归集，失败/待复核/争议不计为错误。
- 问：重新答对后错题会消失吗？答：会；刷新错题本列表后按最新判定移出。
- 问：小测题目会出现在固定题库里吗？答：不会，小测是本人题目，与固定题库分开保存。
- 问：离线时标记状态会丢吗？答：不会立即丢，先写浏览器本地队列；服务恢复后自动同步，页面显示待同步数量。
- 问：随手记保存失败怎么办？答：页面会提示并保留草稿，可重试同步；冲突时提供「保留当前」与「使用副本」两种选择。
