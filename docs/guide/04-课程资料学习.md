# 课程资料学习

> 功能名：课程资料学习工作台。作用是把「课程书架 + 知识图谱 + 资料知识点练习 + 个性化学习计划 + 视频目录」串成一个学习流程，并记录每日签到。

## 功能名与作用

- 课程书架与知识图谱：按资料（课程课件）组织知识图谱，展示章节、知识点、知识点关联的资料题与固定练习，可进入某个知识点查看说明、资料题和相关视频。
- 视频目录：在资料学习页内嵌课程视频目录，方便边看资料边看课。
- 个性化学习：直接嵌入「定制学习计划」工作台（AI 排程）。
- 课程固定练习：进入与当前资料关联的固定题练习（旧题与记录保留）。
- 每日签到：记录当天是否已签到，签到状态显示在页面顶部按钮上。
- 资料准备：把公共/共享资料准备进当前课程（`/materials/prepare`），准备后生成知识点与题目。

## 所属模块

课程学习模块 · 资料学习子模块。前端主控制器 `frontend/js/material-learning.js`，书架图谱 `frontend/js/course-graph.js`，知识点练习 `frontend/js/concept-practice.js`。

## 进入路径

- 侧栏「课程资料学习」→ `#space/materials`。
- 概览「学习中心核心板块」中的「课程学习中心」下方资料入口、资料返回导航等也会落到本页。
- 子标签：`#space/materials/corpus`（书架图谱）、`#space/materials/video`（视频目录）、`#space/materials/plan`（个性化学习）。
- 具体资料与知识点：`#space/materials/{资料ID}/{知识点ID}`。
- 课程固定练习：`#space/practice/legacy`。

## 操作步骤

1. 打开 `#space/materials`，默认进入「课程书架与知识图谱」。上方按钮可切换「视频目录」「个性化学习」「课程固定练习」，右侧可点「每日签到」。
2. 在书架中点选一门课或一份资料，右侧画布显示知识图谱；点击知识点节点查看详情（说明、资料位置、资料题、固定练习、相关视频）。
3. 点击知识点详情里的「知识点练习」按钮，打开该知识点的练习卡（`concept-practice.js`），可以作答、生成补充题目（需要确认外部模型费用）。
4. 点「视频目录」查看课程视频；点「个性化学习」进入定制学习计划。
5. 点「课程固定练习」进入 `#space/practice/legacy`，练习旧题与保留记录。
6. 若资料还没有解析/出题，可在图谱或资料卡片上点「准备资料」触发准备流程；处理中的资料会每隔数秒自动刷新状态。

## 涉及路由

- 页面：`#space/materials`、`#space/materials/corpus`、`#space/materials/video`、`#space/materials/plan`、`#space/materials/{资料ID}/{知识点ID}`、`#space/practice/legacy`。
- 接口：
  - `GET /api/learning/space/materials`：资料目录、知识点、就绪状态。
  - `POST /api/learning/space/materials/prepare`：准备课程资料。
  - `GET /api/learning/space/materials/concept/{conceptId}`：知识点练习数据。
  - `POST /api/learning/space/materials/supplement`：补充知识点题目（外部模型，需确认）。
  - `GET /api/learning/space/course-graph`：课程书架与知识图谱。
  - `POST /api/learning/space/course-graph/continue`：继续构建图谱（AI，需确认外部调用与调用上限）。
  - `GET/POST /api/learning/space/attendance`：读取/记录每日签到。

## 常见问题

- 问：为什么图谱里没有我的资料？答：资料需先完成解析（`#space/knowledge` 中处理），并且资料相关知识点构建完成后才会出现在书架里。
- 问：点「继续构建图谱」会不会自动扣费？答：接口要求先确认外部调用（`confirmedExternal: true`）才提交，且有 1–50 次的调用上限参数，不会自动重试。
- 问：知识点练习生成失败怎么办？答：失败与未知状态不会自动重试；可在页面重新打开知识点查看已保存结果。
- 问：签到有什么用？答：只记录当天学习到场状态，不影响掌握度或计划任务。
- 问：从知识点进入练习后怎么返回？答：页面顶部会出现「返回资料与知识点」导航（依赖会话中的返回位置记录）。
