# 常见问题 FAQ

> 汇总使用学涯 Copilot 时最常见的问题、原因与解决方式。问题按「启动与模型」「资料与检索」「练习与记录」「计划与分析」「账号与数据」分组。

## 功能名与作用

FAQ 用于快速自救：先在这里找现象，再按提示检查配置或进入对应页面。每条都给出可验证的现象与真实入口。

## 所属模块

系统帮助 / 文档。

## 进入路径

- 直接阅读本页；也可以在右下角问小涯「为什么回答未完成」「资料怎么上传」等，它会检索本目录文档回答。

## 操作步骤

1. 在下方找到与你的现象最接近的问题。
2. 按「原因 / 解决」操作；涉及页面入口的，按给出的 hash 路径或侧栏名称进入。
3. 仍无法解决时，把现象和页面路径记录下来反馈。

## 常见问题

### 启动与模型

- 问：页面右上角显示「本地模式」是什么意思？答：本机服务已启动但没有可用的外部模型配置，或模型连接未验证；浏览、资料管理、题库与计划仍可用，AI 生成会降级或失败。
- 问：提示「回答未完成 / AI 暂不可用」？答：检查 `.env` 中的模型密钥与模型名，确认本机网络能访问模型站点；失败请求不会自动重试，避免重复计费。
- 问：服务启动时报端口被占用或已有实例？答：同一数据目录只允许一个服务实例；先关闭已有服务（或运行停止脚本），再重新启动。
- 问：浏览器打开是空白或 404？答：确认访问的是 `http://127.0.0.1:4173`（或实际端口），不要用 `file://` 直接打开 `index.html`。

### 资料与检索

- 问：上传资料支持哪些格式？答：PDF（≤64MB）、PPTX / DOCX（≤10MB）、TXT / Markdown（≤1MB）；不支持的类型和 Office 临时文件会被拒绝。
- 问：资料上传后多久能用来问答？答：需要解析完成并「确认」当前修订；要向量检索还需建立索引。页面上会显示「待解析 / 待复核 / 已确认」等状态。
- 问：为什么 AI 说「资料不足」？答：当前问题在已确认的资料里找不到足够依据；可以补充资料、扩大资料范围，或换一种问法。
- 问：扫描版 PDF 文字识别怎么用？答：在资料行的「处理」里点「选择识别页」，每次最多 20 页，提交前需确认外部 OCR 调用。
- 问：向量索引会重复收费吗？答：建立索引前会显示可复用向量数量；已有缓存匹配时不会重复调用。

### 练习与记录

- 问：题目状态保存在哪里？答：本机服务的当前账号下；离线操作先进浏览器队列，恢复连接后同步。
- 问：代码「运行代码」一直转圈或失败？答：本机缺少对应语言编译器/解释器时会提示不支持；运行有超时与输出上限，这不是强安全沙箱，请只运行自己信任的代码。
- 问：错题本怎么清空某题？答：在错题本中重新答对，或把状态改为「已攻克 / 移回待刷」；刷新后按最新判定归集。
- 问：小测和固定题库有什么区别？答：固定题库是内置题目；小测是本人题目，保留原答案与 AI 评阅、人工修正，仅本人可见。

### 计划与分析

- 问：学习计划草稿会自动执行吗？答：不会，必须在「我的计划」中核对后点「采用此计划」。
- 问：学情分析为什么没有数据？答：所选范围内没有练习记录；先完成几道题或扩大时间范围。
- 问：周期回顾会自动扣费吗？答：默认只准备本地快照；只有显式开启「自动调用外部 AI 生成周报」并确认后才会调用外部模型。
- 问：计划里的任务完成后怎么同步？答：在学习路线或「今日学习」中勾选任务；课程完成也会同步到计划任务。

### 账号与数据

- 问：要不要登录？答：默认单机单用户不需要；在系统设置中启用团队账号后需要登录，资料与记录按账号隔离。
- 问：数据会丢吗？答：数据保存在本机 `.xueya-data`；不要手工删除。定期用顶部「导出记录」导出 JSON 备份，或复制整个数据目录。
- 问：密钥会出现在页面或回答里吗？答：不会；密钥只在本机环境配置中读取，接口与页面都不会回传。
- 问：换浏览器后记录不见了？答：界面草稿与离线队列存在浏览器本地；服务端记录仍在新浏览器登录后读取。

## 涉及路由

- `GET /api/health`：检查服务与引擎状态。
- `GET /api/account/status`：检查账号状态。
- 页面入口：主问答 `#space/ask`、资料库 `#space/knowledge`、练习 `#space/practice`、分析 `#space/analysis`。

## 代码依据

- 相关行为以各模块文档与代码为准：`backend/xueya/app.py`（健康检查/装配）、`backend/xueya/config.py`（环境配置）、`frontend/js/app.js`（路由与状态）。
- 资料处理：`backend/xueya/knowledge_base.py`、`backend/xueya/rag_service.py`；练习：`backend/xueya/practice_api.py`；分析：`backend/xueya/practice_analysis.py`。
