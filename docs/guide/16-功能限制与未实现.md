# 功能限制与未实现

> 记录当前版本真实存在的限制、实验性功能与未接入项，避免把「看起来有按钮」当成「功能已经完整」。本页依据代码与页面实际行为整理。

## 功能名与作用

说明哪些能力是实验性/有条件可用、哪些入口当前不可达、哪些数据指标未接入，以及使用时的边界与风险。

## 所属模块

系统帮助 / 验收边界。

## 进入路径

- 本页文档；相关页面：`#space/analysis`（预测估分）、`#space/media`（录音工具）、`#space/frameworks`（框架历史）。

## 操作步骤

1. 使用某项功能前先查本页是否标注限制。
2. 看到「有条件可用」时，按说明确认前置条件（模型配置、资料确认、账号等）。
3. 遇到「未实现/未接入」，不要期待系统自动完成，改用说明中的替代路径。

## 涉及路由

- 受限页面与接口在各项中逐条列出。

## 常见问题与限制清单

### 模型与外部服务

- 所有 AI 能力都依赖外部 API：未配置 `MIMO_API_KEY` 时问答/计划/分析不可用，只有本地流程与关键词检索。
- 向量检索依赖 `RAG_EMBEDDING_*`（当前配置为 Qwen3-VL-Embedding-8B / 4096 维）：未配置时资料只能关键词检索。
- OCR 与重排各有独立服务配置；未配置时对应按钮禁用或提示不可用。
- 付费调用失败不会自动重试；「结果不明」的调用需要人工核对，系统不会重复提交。

### 页面入口

- 知识框架历史（`#space/frameworks`）没有侧栏入口，只能通过计划草稿/聊天引用或地址栏进入。
- 录音与视频工具（`#space/media`）没有侧栏入口，地址直达；入口链接依赖旧版页面，不一定显示。
- 旧的资料库阅读器（`frontend/js/library-workspace.js`）保留代码但未接入当前路由：`#space/library` 会被重定向为 `#space/knowledge`。
- 旧版算法演示页（`frontend/js/algorithm-demo.js` 的 `#space/algorithms` 挂载）不会出现在常规导航中；交互演示以题目详情里的独立实验室页面 `/algorithm-demo.html?question={id}` 为准。
- `#space/graph` 不是有效视图，课程知识图谱在 `#space/materials/corpus`。

### 题库与练习

- `hot100`、`exam408` 之外的旧题入口（`foundation`、`interview`、`legacy`）属于保留兼容入口，题目与记录不删除但不再是主推路径。
- 交互演示以 `frontend/js/algorithm-demo-registry.js` 注册表为准（当前 Hot100 100 题均有后端追踪数据）；注册表之外或追踪失败的题目会明确报错 `DEMO_*`，不会伪造步骤。
- 代码运行是本机单用户执行（临时目录 + 子进程 + 超时/输出上限），不是强安全沙箱；不支持的语言无法运行，但可以查看题解。
- 408 站内题目是改编/原创模拟题，不是历年真题；「预测估分」未接入，页面显示「—」。

### 资料与检索

- 个人资料库页面当前不渲染独立检索表单；检索通过主问答（课程资料 RAG）或内容搜索完成。
- 扫描 PDF 未 OCR 前不能作为完整知识库；图片/图示内容需要人工核对，模型不保证读懂图片。
- 资料删除会同时删除向量索引；校正产生的新修订需要重新建索引。
- 学习计划关联的知识框架/图谱生成失败时不会自动重试，计划本身仍可采用。

### 数据与账号

- 单机单用户为主；启用本地账号后数据按账号隔离，但不同电脑不会自动同步。
- 页面 UI 草稿、离线操作队列依赖浏览器本地存储，清理浏览器数据可能丢失未同步草稿。
- 导出记录只导出学习记录 JSON，不含原件与向量缓存；完整迁移需复制 `.xueya-data`。

### 实验性与有条件可用

- 本轮改造中的「桌宠系统助手」依赖 `materials/system-guide/` 向量与模型服务：模型不可用时以本地指南降级回答；向量不可用时降级关键词检索。
- AI 组卷、AI 补充题目、AI 继续建图等都会产生外部费用，均需要勾选确认且可设置调用上限。
- 「深度思考」「联网搜索」为显式开关，默认不启用；不开启时不会触发对应外部能力。

## 代码依据

- 路由与回退：`frontend/js/app.js` 的 `route()`。
- 媒体工具入口：`frontend/js/media-workspace.js` 的 `mount()`。
- 资料库阅读器：`frontend/js/library-workspace.js` 的 `mount()`（`state.view !== 'library'` 时直接返回）。
- 资料库页面：`frontend/js/knowledge-base.js` 的 `draw()`（当前无检索表单）。
- 练习页面：`frontend/js/practice-view.js`、`frontend/js/practice-hub.js`。
- 模型与向量配置：`backend/xueya/config.py`、`backend/xueya/rag_http.py`。
