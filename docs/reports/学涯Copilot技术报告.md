# 学涯 Copilot 技术报告

版本：2026-10-25 代码交付说明。报告描述已实现能力、可复核验证和已知限制；真实模型质量、人工评审及比赛格式尚未全部验收，不将其表述为完成的研究结论。

## 1. 目标与技术架构

系统以课程资料为证据，串联阅读、问答、知识整理、练习、订正与复习。浏览器采用 HTML/CSS/JavaScript；Python/FastAPI 提供统一 HTTP/SSE 服务；SQLite 保存资料版本、学习产物、作业、回执和审计记录。AI 推理只调用外部 API，不部署本地模型或 GPU 运行时。

| 层次 | 实现与职责 |
| --- | --- |
| 页面 | `frontend/`、`shared/`：课程空间、资料范围、进度、引用与确认 |
| 主宿主 | `backend/xueya/server.py`、`app.py`：生命周期、鉴权、路由、静态资源与流式响应 |
| 平台 | 数据库、仓库、文件、任务、备份、权限、操作回执及模型账本 |
| RAG | 解析、结构分块、文档版本、检索、证据预算和出处检查 |
| 学习领域 | `backend/agent/`；通过 `learning_integration.py` 复用主平台 |
| 工具 | MCP 注册、发现、作用域、审计、取消及写操作预览／确认 |
| 模型 | 文本、图像、语音和检索增强按实际配置访问外部 API |

请求路径为浏览器→本机鉴权与课程作用域→作业／领域服务→RAG／Agent／MCP→可选外部模型→核验结果→预览→用户确认→事务保存。兼容工厂仍用于专项测试，不是第二个生产入口。[HTTP/SSE 契约](../api-contracts.md)、[学习服务契约](../contracts/learning-services.md)。

## 2. 数据、证据与保存

原件、解析产物、片段和学习成果分别版本化。引用包含文档、版本和实际位置；片段存在并不自动证明语义支持。资料更新或删除后，旧快照必须重新检查。学习产物使用独立命名空间，避免与检索 artifact 混淆。

写入携带操作 ID 与预期版本：相同请求回放当时的原回执，不同请求复用同一操作 ID 时冲突；版本不符不覆盖人工修改。预览与采纳分开，流式增量只作暂态，最终通过校验的结果才保存。

私人数据库不随 Git 同步。备份使用 SQLite backup API 生成一致快照，并核对不可变原件；恢复到新目录验证，不直接覆盖正在运行的数据目录。[运维说明](../platform-guide.md)。

## 3. 检索、Agent 与学习闭环

资料通过作业解析并形成有出处的结构片段。词法检索不调用模型，向量／混合／重排与 OCR 按外部服务配置开放。上下文压缩遵守字节预算，保留引用位置和冲突提示；历史对话用于理解追问，不能冒充教材来源。

Agent 将意图、计划、工具执行、观测和完成核对分开，限制轮次、用量和无进展循环。取消传播至模型和工具，远端结果未知时不自动重放。持久化检查点允许重启后检查和恢复，写入前仍需确认。

学习领域支持章节学习包、候选题审核、多题型作答、人工订正、诊断反馈、FSRS 复习、概念先修和按可用时间生成计划。题目与作答保留当时快照；不凭单次作答给出精确掌握度。完成、跳过、延期和剩余量明确区分。

图像、ASR、TTS 和视频采样需要相应 API。识别结果可校正，视频只反映实际采样帧；时间来自真实片段，不虚构逐字对齐。听完音频不自动计为掌握。

## 4. 软件验证

最近代码候选在 Windows、Python 3.12.7、Node 24.19.0 上执行完整严格 pytest **567 项通过、无警告**，前端 **42 项通过**；MCP 独立检查发现 4 工具并检索命中 2 条，pip check 与 Python／JS 语法检查通过。最终文档清理复核见 [交付说明](../delivery/FINAL-DELIVERY.md)。

本轮代码重构新增 72 项特征测试，验证校验优先级、答案隐藏、路径顺序、作答与幂等、历史评分量规、计划动作和运行恢复。纯排版比较 AST 等价；局部算法以固定输入对照完整结果、异常、存储及验证顺序，不修改原测试迎合实现。

当前环境缺少 Playwright，三套 Node 浏览器回归未进入页面场景；不能沿用旧测试记录宣称本次已通过。未配置独立 lint、类型检查或构建入口。受控上游与软件回归不等于真实模型效果验收。

## 5. 原创离线评测

`F-acceptance-v1` 含 60 问，dev 14、test 46：24 个事实的两种问法、跨资料冲突和不可答问题。标注由 AI 辅助构造，待人工审核；不作为真实教师黄金集或独立学习效果研究。[数据与复现说明](../../evals/acceptance/README.md)。

固定分块（600 字符、80 重叠）与结构分块使用相同词法函数、top-k=6 和 2000 UTF-8 字节摘录预算。预算不是模型 token。结构服务还包含数据库与版本检查，不能将两种整体耗时当作隔离算法变量的严格消融。

| 方法 | test 通过 | 全部证据召回@6 | 摘录召回@6 | MRR@6 | 负例无证据率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 固定词法 | 43/46 | 1.000 | 1.000 | 0.975 | 0.500 |
| 结构词法 | 40/46 | 0.925 | 0.932 | 0.875 | 0.500 |

短问法的树遍历召回存在不足，不能宣称结构分块优于基线。负例的相关片段被召回不等于生成答案必然幻觉；引用位置正确也不代表支持结论。同分检索受随机导入 ID 影响，尾部证据可能变化。

[首次基线原始结果](../../evals/acceptance/results-2026-10-17/results.json)与 [C 合成规则实验](../../evals/acceptance/results-2026-10-17/c-rules-results.json)保留原运行日期和元数据，供复核方法与回归，不改写成新的真实模型测试。合成场景不足以证明长期学习收益。
