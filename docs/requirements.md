# 当前产品约束（优先于旧计划里的技术候选）

2026-10-16用户明确决定：**现在及以后，所有AI能力只调用API，不接入本地模型。**

- 问答/多模态生成、OCR、Embedding、Rerank、ASR、TTS等通过服务端配置的外部API实现；不能要求用户安装本地模型、CUDA、GPU运行时或Python推理Worker。
- 前端保留HTML/CSS/JavaScript，后端整体采用Python＋FastAPI，包括RAG、Agent、MCP、HTTP、SQLite仓库及后台任务。Python用于调用外部API和普通业务处理，不加载本地AI模型。
- E仅调度`cpu`普通处理和`api`外部调用；GPU资源池、模型加载/卸载、显存管理、本地推理/CPU模型回退从当前开发要求中撤除。
- 付费调用有并发、超时、取消和用量记录；请求发出后结果未知时不能保证不扣费，不能自动重试未知付费结果或填写猜测费用。
- OCR/向量化等API尚未选型或接入时明确未接通，不能为了让按钮变绿伪造结果。MiMo继续作为当前生成API，其他能力由B/C选择真实支持的服务并验证。
- 长计划和W卡中旧GPU/本地模型建议属于历史技术候选，按本页替换为API适配与实测；功能目标仍保留。F的报告测API质量、时延、Token/费用、错误与重试边界，不安排本地模型/GPU实验。

用户已明确选择后端整体迁移Python，不只迁移AI模块。旧Node后端约定在迁移分支中撤销；JavaScript仍用于前端、离线规则和浏览器测试。

其他需求仍为个人学习优先、本地运行、预留多课程/协作扩展，11月18日提交并准备技术报告。以上是用户的产品决定，不是因时间或工作量缩减功能。
