# 产品与工程约束

- 个人学习、本地运行优先；保留课程隔离，不将本机团队账号称作跨电脑云同步。
- 前端采用 HTML/CSS/JavaScript；后端、后端测试、CLI 和运维验证使用 Python/FastAPI，不以 Python 包装旧 JavaScript 后端代替实现。
- 所有 AI 推理只调用外部 API，包括问答、图像、OCR、Embedding、Rerank、ASR 和 TTS。不要求本地模型、CUDA 或 GPU 推理环境。
- CPU 仅处理普通业务，外部调用复用主平台的 API 并发、预算、超时、取消及用量记录。不增加重复数据库、检索或学习算法实现。
- 资料、引用、题目与学习事件保留真实出处和版本；预览不等于保存，写入需明确确认和版本校验。证据不足和能力未配置时明确说明，不伪造结果。
- 远端调用发出后可能结果未知，不保证供应商没有扣费，不自动重试未知付费请求；Token 用量不是实际账单。
- 密钥仅存本机 `.env`，私人数据库、原件、日志、依赖环境和测试输出不进入 Git。
- 公共 HTTP/SSE、数据库结构和配置格式变更须明确授权。可读性重构保持外部行为，分批验证，不修改原测试迎合实现。

运行、接口与交付限制以 [README](../README.md)、[API 契约](api-contracts.md) 和 [最终交付说明](delivery/FINAL-DELIVERY.md) 为准。
