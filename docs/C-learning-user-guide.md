# 在页面使用 C 学习功能

Windows 可直接双击项目根目录的 `启动学涯.cmd`，自动启动并打开网页。

在项目目录运行 `python -m pip install -r requirements.lock`，再运行 `python -m backend.xueya.server`，浏览器打开 <http://127.0.0.1:4173>。服务已在运行时，更新代码后先正常停止再重新启动。

进入学习空间后，每页顶部都有 **打开本页进阶学习功能**，顶部工具栏也有 **章节与进阶学习**。点击即可定位到本页新的学习服务区域；原有浏览器功能和记录仍保留。

## 第一次使用

资料较多时先展开“学习资料范围”，选择一章或少量文件。页面原文目录为有界预览，生成仍读取所选范围的完整原文；过大请求会提示缩小范围。各页已保存产物按类型分页，更多记录点击“加载更多已保存内容”。

1. 选择当前课程，先上传课程资料。已有浏览器资料时，打开 **本地数据**，预览迁移并确认启用同步；原件仍需保留或补传。
2. 点击本页进阶学习入口，展开 **学习资料范围**，选择这次要学的文件。不选特定范围时，使用当前课程全部有效资料。
3. 生成结果先预览。点击 **确认采纳并保存** 才写入当前课程；章节任务需查看结果并确认后继续保存。
4. 已保存内容会显示版本号，刷新后仍保留。未采纳的服务端预览在有效期内可恢复；未提交的测验和表单输入保留浏览器草稿。图片、音频等本地文件不能由浏览器自动重新选择。

## 各页面可以做什么

| 页面 | 操作 |
| --- | --- |
| 学习概览 | 生成完整章节学习包、章节总结、多资料对照、今日学习安排；调整推荐；查看已保存学习包 |
| 资料问答 | 在进阶区域按所选资料提问，查看原文依据、章节总结或多资料对照 |
| 课程资料 | 选择文档范围，生成章节学习包或总结；学习任务在本页下方统一管理 |
| 知识卡片 | 新建和编辑学习笔记；查看版本并预览恢复旧版本；查看学习包和总结；朗读已核对内容 |
| 练习与错题 | 生成候选题或添加单选自测题；编辑题目及答案；核对出处后采纳；组卷、作答、评分、主观题复核、订正错因和生成变式 |
| 记忆卡片 | 从原文创建记忆卡，确认保存，查看当前到期队列；翻面后按四级评分复习；延后或编辑卡片，查看 FSRS 复习历史 |
| 复习计划 | 设置目标日期、每天时间和休息日期；预览并采纳计划；标记任务完成、跳过、延后；调整条件重排 |
| 知识图谱 | 提取候选概念/关系，人工核对采纳；手工添加有出处的概念和先修关系；查看学习路径；预览清空后重建 |
| 多模态学习 | 图片识别后人工校正，再核对逐行解题步骤；WAV/MP3 转写后校正并保存笔记；视频抽帧分析；从已保存笔记/总结/记忆卡生成语音 |

生成的多选、判断、填空和简答题都可审核、编辑答案并组成测验。简答题按评分要点人工复核，不会把模型猜测当作评分事实。旧服务端题库可导入为候选题，重新审核；缺少历史题目/原文版本的旧作答仍保留，但不伪造成新的掌握度证据。

## 生成进度与确认

每页下方的 **学习任务与确认** 中可以查看章节任务进度、取消、核对结果和恢复任务。完成生成并不自动写入笔记或覆盖计划。调用结果不明时，需要你先核对，再选择是否允许再次调用。

章节学习包中的计划与当前正式计划分开。需要使用时，点击 **提取计划并预览**，确认后另行保存。

## 模型和资料状态

- 图像、语音、音频转写和模型生成需要 `.env` 中有效的 MiMo API 配置；图片还需要支持图片的模型。全部使用外部 API，不运行本地模型。
- 未配置模型时，原文摘录、手工笔记、自建测验、记忆卡和有实际数据的计划仍能使用。不能执行的模型操作会明确说明原因。
- 图片题干必须先核对；转写不是逐字对齐；视频仅分析实际抽取的三个画面，不代表理解全部视频或音轨。音频片段限 7MB，视频限 50MB / 30 分钟。
- 引用与原文版本会复核。资料替换或删除后，过期预览不能直接采纳。缩小资料范围时，学习编排仅采用范围内有有效依据的概念，原课程图谱不会被修改。
- 直接打开 HTML 仍可使用原有浏览器功能；需要数据库和模型的进阶功能请通过本地服务访问。
