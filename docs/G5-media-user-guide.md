# 录音与复习音频怎么用

先启动本地服务，进入学习空间，点击右上角 **“录音与复习音频”**。不要通过 file:// 直接打开 HTML 使用服务功能。

## 录音和转写

1. 展开“导入录音或录制一段”，选择音频和每段秒数，点“保存原件并免费分段”。也可以点开始录音，允许浏览器使用麦克风，再点停止保存。
2. 在下方进度中等分段完成，点“确认分段转写”。页面会列出片段数和调用上限；确认使用已配置服务及费用后才识别。没配置服务时，原件仍可保存、播放和免费分段。
3. 完成后点查看结果，逐段回放，修正文字并勾选核对，保存。时间来自实际录音片段，不是逐字对齐。
4. 点“确认导入资料并关联原件片段”。完成后在课程资料页阅读，可回到实际录音位置；转写和原件都保留版本。

当前单文件上限一小时/120MB，分段最多120段。普通音频由浏览器解码转换，同时保留原始文件；识别使用 PCM 处理副本，原件和副本有版本关联。PCM WAV直接校验；浏览器不支持的容器需先导出WAV。大文件可能受本机内存限制，建议按课次拆开。录音离开媒体页会停止并在当前课程保存；切换课程前应先停止保存，避免混入另一课程。

## 课程视频

选择50MB、30分钟以内的视频，填开始/结束时间和1～24帧，先保存原件与实际采样画面。之后再明确确认画面分析调用。查看结果时可跳到对应时间，核对观察、不确定内容与推断，修正画面说明；需要时确认导入课程资料。

只处理采样画面，不代表听懂视频音轨或理解整段课程。要识别音轨，请将音频导出后走录音转写。浏览器不支持的视频格式需先转换为可播放的MP4/WebM。

## 制作复习音频

1. 展开“制作有出处的单人/双人复习脚本”，选择资料、有出处的笔记或复习卡，也可选择今日到期卡片。第一版用原文模板免费建立脚本。
2. 核对各段：导入重点、原文解释、适用条件、回忆问题、留白、参考答案和复习提示。可以编辑文字、角色和留白时长；点击引用按钮能重新读取当前原文。逐段勾选后保存脚本。
3. 在已保存脚本中点“确认合成音频”，选择两个角色的已有音色，确认本次调用上限与费用。单人脚本只使用讲解者角色。修改脚本后，相同配置和未变化段落的音频会复用。
4. 完成后可逐段播放或顺序播放，回忆处会留白；也可下载包含完整WAV、脚本和字幕的压缩包。
5. **听完不会自动算掌握。** 关联复习卡后，先回忆、核对答案，再明确提交自评；或进入原题库真正作答。

## 停止、恢复和限制

- 取消后台执行会停止后续片段；已经发送的请求仍可能收费。成功片段保留。
- “结果不明”先核对服务商记录，再明确恢复未完成部分；系统不会自动重放收费请求。配置改变后应新建任务核对。
- 服务配置仍在本机 `.env`，前端不接收密钥。未配置不代表连接成功。
- 当前软件流程已用受控服务检查。真实口音、噪声、公式/表格、长视频、声音自然度和供应商实际账单需另行验收；开发验证没有新增付费调用。
