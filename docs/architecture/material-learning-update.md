# 2026-11-05 用户补充后的信息结构

资料学习依次为：①按实际已有资料组织的课程书架与知识图谱；②仅匹配这些科目的视频目录；③选择科目、起止日期/每日时长/休息日与难度的个性化学习，生成阶段计划与可打开题目、课程的阶段导图。单份文件详情降为辅助入口，示例记录不作为真实书籍。视频仍为可信来源课程，不伪造自动生成的视频或精确分集。

新增CourseGraph复用既有平台JobQueue、SQLite、Question与Attempt。每个可信source完整按1800字符范围切分（含末尾），以来源scope/文件hash/修订/范围hash幂等标识。成功范围复用，续做只提交未开始范围；每次用户确认外发/费用并限定1至50请求，后台持久执行，未知/失败不自动重放。GET不触发调用。逐范围提取不再只取整本书最前18000字符；已有首批图谱仍展示。

图谱按课程/资料/知识点包含关系组织，跨资料按同学科NFKC/大小写/标点归一化标题去重，同题型同标准化题干去重，保留原引用与作答ID。此规则不是语义同义词融合；先修关系不推测。活动版本、权限和归档在读取及发布再次核验。覆盖率为实际输入范围处理率，不等于学术知识点审校率。跨账号与六份公共清单授权范围保持。

目前仍没有全自动无限费用补齐、未知调用自动重放、视频分集内容自动审校和精确知识点定位。用户可按预算多次继续，成功范围不重复付费。

# 资料学习新方案与实现边界

2026-11-04用户确认的新方案优先于旧规格的冲突条款。开发仅使用 `codex/test-learning-space-20261031`。

## 已确定要求

- 顶层为AI问答和学习平台；学习内并列课程资料学习、算法学习、408考研学习，资料学习为主体。
- 默认展示当前账号可用的全部学科；不自动认领匿名旧资料，不扩大既有公共权限。
- 私人资料可信解析完成后自动出题，需要校正的上传在本人确认修订后自动准备。向量索引不是出题前提。已有可访问资料进入学习页时准备尚无作业记录的批次。
- 单选、多选、判断、填空；AI题明确未独立审校。资料图谱节点关联真实题目，计划阶段图谱引用同一知识点。
- 计划包含学科/专题、难度、起止日期、每日时间、休息日；草稿须明确采用。签到单独记录，不代表任务完成或掌握。
- 正规视频原站链接或允许的嵌入，未知匹配如实说明。代表性算法支持播放、暂停、步进、重置和状态观察。
- 408区分原卷、改编/原创固定题、程序模拟卷和AI选题模拟卷；尝试计时考试、保存、交卷、评分和整卷解析。

## 资料生成范围

复用同一SQLite、Repository、JobQueue及调用账本。`material-learning` 是持久API作业。仅唯一私有owner映射可在解析回调自动提交；公开材料继续通过原ScopeAdapter授权，正文仅在内部处理，不扩大公开原文接口。

一批最多读取18,000字符，每片段最多3,000字符。单次输出遵守 `AI_MAX_OUTPUT_TOKENS`，最多六个知识点、每点最多四题；4096上限时最多两个知识点、八题。这是有费用上限的首批，**不是整本教材覆盖承诺**。记录选中/全部片段数，截取时显示部分覆盖。后续章节自动补建和更细覆盖仍待增强。

相同账号、原课程、文件哈希及内容修订复用批次。失败/unknown不自动重放。发布前重查权限、活动状态及修订。未作答投影移除答案，图谱只返回说明及位置元信息。

规划仅读取题目元信息；命中资料题目时生成阶段图谱并保留原 `conceptId/materialId`，不重复创建独立知识体系。普通无资料关联计划沿用自由框架。图谱修改不改变任务日期或完成状态。

## 资源与考试边界

原7门/22章节ID及历史保留为 `legacy-unverified`。新增四科MOOC总览链接，2026-11-04原站元信息已核对；计划可打开课程总览，不虚构逐视频映射、嵌入权限、播放遥测或时长。未知专题可能没有匹配视频。

厦门工学院2009—2025原卷及整理解析按年份提供原站链接，站内固定题仍为改编/原创，原卷未结构化接入站内自动评分。

模拟考试首版使用固定单选候选，保存不可变题目快照，服务器决定截止时间，逐题保存，刷新恢复。到时在下一次访问核验时交卷，不依赖客户端宣称用时。主观题继续在原分科作答及参考评阅链，不称为整套原卷已自动阅卷。单题等权计分，不冒充正式150分结构。

程序组卷不调用模型；AI组卷只接受提供候选内的真实、唯一ID。候选不足则拒绝；超额合法推荐由程序按科目轮选到精确题量，明确标记并保留推荐数及选编数，不把候选列表直接冒充整卷。真实模型质量、正式题目审校和资源播放验证须与受控测试分开报告。
