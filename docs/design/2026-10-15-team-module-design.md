# 四项任务的模块整理

## 目标

保留当前页面、浏览器本地存储、上传、问答、引用、卡片、练习和计划行为。沿用 `/api/health`、`/api/ai`、启动命令和旧的共享学习接口，不增加服务依赖。

## 边界

- 界面：`frontend/index.html`、CSS、动效和 `frontend/js/ui/`；控制器只管理页面状态与交互。
- RAG：`shared/rag/` 提供浏览器与 Node 共用的分段和关键词检索，`backend/rag/` 提供可替换的异步服务，前端资料服务处理本地文件读取。
- Agent：`backend/agent/` 编排资料、提示词与回答校验；模型 HTTP 调用独立在 `backend/providers/`；前端问答服务负责请求和离线回退。
- MCP：`backend/mcp/` 提供工具注册、发现适配与显式调用入口；默认无外部连接，不自动执行模型返回的工具命令。
- 公共契约：`shared/contracts/` 固定请求、来源、回答、工具格式与限制；`shared/fixtures/` 保存明确标记的示例课程。
- HTTP、环境配置和服务装配由联调负责人维护，模块通过传入依赖连接。

## 兼容与范围

当前 RAG 是本地文本分段与关键词检索，不声称已经有向量库。PDF/DOCX 仍仅保存记录。MCP 提供真实可测试的工具网关与适配器边界，不声称已连接真实 MCP 服务。保留原本的示例课程和 localStorage 键，旧引用和记录继续可用。

## 验证

先运行现有 8 项测试作为基线；新增模块接口、工具超时与失败、Agent 来源校验、浏览器问答服务和离线回退测试；运行资源路径、安全隔离、语法检查及浏览器关键流程回归。
