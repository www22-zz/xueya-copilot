# 学涯 Copilot 全新网站设计方案

日期：2026-10-14
状态：用户已确认推荐方案，进入实现

## 任务与现状

保留学涯 Copilot 的课程学习定位与主要功能，重新设计网站的布局、视觉语言和交互。原网站的颜色、侧栏、卡片布局和样式均不作为新版视觉依据。

已阅读技术介绍、旧设计文档、index.html、app.js、server.js 和现有浏览器检查脚本。原项目使用原生 HTML/CSS/JavaScript 与 Node.js MiMo 代理，可继续在本地运行。现有上传仅保存文件记录；知识卡片只保存时间；考试日期不持久化；练习生成和重排主要是演示反馈；多轮对话没有传到模型。这些行为需要在新版中改进或准确标明。

## 三种方向

1. **推荐：品牌首页 + 专注学习空间。** 首屏建立独立品牌形象，以动态知识连接为主视觉；进入学习空间后提供清晰的工具界面。兼顾作品展示与实际使用。
2. **直接进入学习工具。** 所有功能从一个简洁工作空间访问，操作更快，但品牌表达与滚动叙事较弱。
3. **全站沉浸式展示。** 深色全屏章节与丰富滚动效果，视觉冲击强，但频繁学习时操作路径更长。

## 推荐方向的视觉设计

首页采用明亮、通透的纸白与雾蓝，局部使用深靛色的大幅展示。配色令牌：纸白 #FAFBFE、雾蓝 #EEF2FA、墨色 #172036、靛蓝 #4058D8、浅紫 #B6B9F4、线条 #DEE3EE。正文和中文标题采用清晰的系统无衬线字体；英文品牌标题使用有辨识度的几何无衬线字形；公式和日期使用等宽字体。

首页顶部为轻量导航，首屏展示“让知识，真正连起来。”与明确的“进入学习空间”入口。原创主视觉将课程材料、问题、引用与知识节点连接成可缓慢运动的知识星图，表达产品的真实工作流程。版面以宽阔留白、大字号、少量精细组件建立节奏，避免旧版密集的指标与卡片堆叠。

首页内容顺序：品牌首屏 → 从材料到理解的交互演示 → 引用与知识卡片展示 → 练习与复习计划 → 进入学习空间。展示里的入口必须能进入对应实际功能。

参考来源：https://www.apple.com/macbook-pro/ 、https://openai.com/ 、https://linear.app/ 、https://stripe.com/ 。提取大字号与视觉焦点、简洁的提问入口、产品细节展示、章节节奏等原则，使用原创图形和产品内容。

## 学习空间

重新设计轻量顶部导航和课程上下文，提供概览、问答、资料、知识卡片、练习、计划。问答以正文阅读为中心，引用通过可关闭的侧面面板查看；移动端使用全宽面板。

- 问答：保留 MiMo 代理及本地演示回退，增加请求状态、防止重复发送、真实来源标识、追问上下文和超时反馈。未找到资料时明确说明。
- 资料：支持上传与拖放、搜索、格式和大小校验。TXT/MD 实际读取内容并用于检索；未增加 PDF/DOCX 解析依赖时明确显示“已添加，内容待解析”，不可假称已索引。
- 知识卡片：保存实际标题、正文和来源；可浏览、搜索与移除；与旧本地状态兼容。
- 练习：提供真实的题目切换、提交、解析、答题记录与错题复习。内置练习明确为示例题库，不声称自动生成未生成的题目。
- 计划：可编辑考试日期和每日学习时间；按剩余天数及错题生成近期任务；支持勾选完成和保存状态。
- 搜索与快捷操作：能找到页面、资料与知识卡片；键盘可以完成主要操作。

## 动效

品牌首屏一次性分层进入，文字与图形错开约 50–70ms；正文滚动进入使用小幅位移与透明度，约 450–650ms。知识星图只在可见时缓慢运动，提供暂停按钮。页面切换约 180–240ms；引用面板与弹窗约 220–280ms；按钮按压与状态反馈约 120–180ms。以 transform/opacity 为主，触摸设备不触发悬浮移动；系统减少动态效果时停止背景运动与视差，保留轻柔透明度反馈。不劫持滚动。

## 实现边界

沿用本地项目运行方式，重新编写页面结构、样式和前端交互，将数据、学习逻辑与动效分成有明确职责的文件。服务端只做支持本次功能所需的修改。密钥保留在服务端。学习状态保存在浏览器，界面明确告知保存位置；不新增账号、云同步或收费系统。

## 验收

1. 首屏、导航和学习空间与旧版形成明显区别，包含原创主视觉。
2. 首页所有主要入口有效，学习功能形成完整可用流程。
3. 上传文本可以被检索引用，知识卡片和计划刷新后仍可恢复。
4. 练习能记录正误，错题与计划有一致的状态。
5. 模型失败时能继续使用明确标识的本地演示模式。
6. 验证桌面、平板和 375px 移动端布局，无横向溢出。
7. 验证键盘操作、面板焦点恢复、减少动态效果和浏览器错误。
8. 提供本地预览与新版截图，并说明实际验证结果。
