# Agent 连续对话与取消体验优化

本次根据现有实现修复三个可复现的问题：泛指追问在 MCP 再检索时丢失原文；用户无法停止生成；网络或服务断开后学习分析和计划退回普通资料摘录。

保留当前每次请求独立 MCP 会话和有界工具调用。相较于引入常驻连接池或增加外部工具，本次优先修复真实学习流程，避免扩大部署和状态管理成本。

## 实现约定

- 共享任务模块负责路由、追问检索词、学习统计与计划文字；浏览器离线和后端采用相同规则。
- 泛指追问优先利用近期用户问题恢复检索语境；检索没有命中时，可以读取本次资料目录中仍有效的上一轮来源 ID。历史回答只能辅助理解，不能作为引用原文。上一轮 ID 最多三个，不能引用当前目录外的资料。
- 页面提供“停止生成”，取消浏览器请求并传到 HTTP、模型和 MCP。主动取消不能变成本地回退，也不把未校验的半段答案保存为正式回答；输入框保留问题便于重试。
- 网络失败或直接打开 HTML 时，复习分析与计划预览使用当前本地学习记录，返回相同的统计和计划结构；预览仍不写入已保存计划。
- SSE 读取支持取消和完整事件大小限制，避免等待中的流和过大的事件拖住页面。

## 验证

用单元测试复现追问缺少来源、主动取消被吞掉和离线计划退化；新增 HTTP 取消传播检查。完整回归保留真实 MCP 测试，并通过浏览器验证连续追问、停止后重新发送、网络失败后的计划预览及原有功能。
