# 408练习题库（2026-10-29）

首版实际300道：240单选、60综合应用，四科覆盖。算法Hot100和资料入口与此题库独立。

## 内容与来源

| 类型 | 单选 | 综合 | 合计 |
| --- | ---: | ---: | ---: |
| 历年考点改编 | 137 | 14 | 151 |
| 项目原创及既有原创选编 | 103 | 46 | 149 |
| 合计 | 240 | 60 | 300 |

历年考点参考2009–2025年公开整理资料，原卷和整理解析链接逐题保留，主来源为[厦门工学院408备考资料](https://www.xit.edu.cn/yjsfk/kyzykwtkw/list.htm)。高校整理解析不称为考试院官方答案。题目元数据中的year、originalNumber用于追溯参考来源，不表示站内独立版本就是该年原题。

当前采用“历年考点改编＋原创”，并非原卷真题逐字收录。这是相对“真题为主”的交付差异，需要如实保留。改编题独立重写了条件、选项、小问及推导，部分参数变化，答案和评分以站内版本为准。原卷链接不是改编题答案，不批量镜像外部原卷或解析。全部300道完整可读，60道综合含147个小问；阅读和作答不再依赖远程PDF成功加载。

四科各题数：数据结构90、计算机组成原理86、操作系统67、计算机网络57。按25章组织，每题有章节、细分知识点和标签；章节连续排序，可用科目、题型、知识点或关键词筛选。难度首版统一标为中等，不声称经过实测标定。

## 可复现构建

- backend/agent/exam408_adapted.py：137道独立编写的考点改编单选及推导。
- backend/agent/exam408_cases.py：14道完整考点变式综合及分步评分。
- backend/agent/exam408_authored.py：33道组成单选、36道四科原创综合；其余复用项目已有原创题和算法题。
- backend/agent/exam408_topics.py：四科25章及细分点的显式归类。
- backend/xueya/data/exam408_selection.json：仅来源、年份、题号、知识点元数据，无外部题干。
- backend/xueya/data/exam408_sources.json：2009–2025年题卷与整理解析地址。
- backend/xueya/data/exam408_bank.json：可直接加载的固定300题。

在仓库根目录运行：

```powershell
.venv/Scripts/python.exe -X utf8 -m scripts.build_exam408_bank
.venv/Scripts/python.exe -X utf8 -m scripts.build_exam408_bank --check
```

构建不联网、不调用AI；check核对已提交数据是否与源码逐字段相同。编号用于展示，题目ID用于保存记录；原算法100个ID不变。修改题意时应复核已有笔记和旧作答，不能假定旧答案仍适用于新条件。

## 作答规则与边界

单选本地与服务端使用固定答案。综合题可保存每小问答案、对照独立参考解答并填0至该问上限的自评分，允许半分；建议分值不是官方评分标准，也不自动诊断语义正确性。草稿、离线队列、笔记和自评分按账号隔离。自评不增加客观题正确或错误计数。

运行时验证能检查结构、数量、来源标记、评分范围与保存流程，不能证明所有答案无学术争议；人工审阅发现的歧义应明确条件并修正，不靠模板复制或随机换数字补数。未运行付费模型或GPU。外部原卷地址未来可能失效，不影响本地改编练习作答；原卷每页及官方评分未逐页核验，不宣称已完成整卷复刻。
