## SQ01 线性表、抽象数据类型与存储结构

线性表描述元素之间一前一后的逻辑关系。栈和队列都限制了线性表允许操作的位置：栈在同一端插入和删除；普通队列在一端插入、另一端删除。它们的核心是访问规则，不要求底层必须使用数组或链表。

抽象数据类型（ADT）说明“允许什么操作、操作产生什么结果”。存储结构说明“数据放在哪里、如何维护”。同一个栈ADT可以用数组或链表实现；同一个队列ADT可以用循环数组或链表实现。不能把“栈”等同于数组，也不能把“队列”等同于链表。

### SQ01.1 数据元素、线性关系与线性表

数据元素是本次操作视为一个整体的对象，可以是整数、字符，也可以是一条任务记录。记录内部可以有多个字段，称为数据项。例如打印任务可以包含任务编号、文件名和页数；队列控制的是任务记录的处理顺序，不会自动把记录中的字段拆成多个队列元素。

线性结构中的元素有先后关系：除了第一个元素，每个元素有一个直接前驱；除了最后一个元素，每个元素有一个直接后继。“线性”描述逻辑次序，不表示它们在内存中必须排成连续一段。栈、队列、数组线性表、链表的关系需要分清：数组和链表可以用来存储有线性关系的元素，栈与队列进一步限制允许的操作。

### SQ01.2 顺序存储与链式存储

顺序存储常用数组，把元素放在连续存储空间中。已知合法下标时可直接访问对应位置；但在中间插入或删除并保持紧密排列，通常需要移动后续元素。栈把操作限制到末端，循环队列通过移动下标复用空间，因此不必每次都整体搬移。

链式存储把数据与后继指针放在结点中，结点不要求物理相邻。给定当前结点才能沿next找到后继；单链表通常不支持像数组那样按第k个位置O(1)随机访问。已知相关结点位置时，局部接链或摘链可以O(1)，但“先找到第k个结点”可能需要O(n)。

### SQ01.3 下标、指针和值不是同一回事

数组下标是位置编号。长度为N的C++数组合法下标为0到N-1，`data[2]`表示取下标2位置的值，不表示这个值一定等于2。队列的front、rear若是整数，就记录数组位置；若是`Node*`类型，就保存结点地址。变量名字相同不意味着类型与含义相同。

C++中`Node* p`声明一个结点指针；`p->next`访问p所指结点的next成员；`nullptr`表示不指向任何对象。使用`p->...`前必须确保p指向有效、仍存活的结点。`delete p`释放结点后不能继续通过p读取数据，也不能重复释放；必要的数据应在释放前保存。

### SQ01.4 空、满、长度与容量

容器长度（size）是当前有效元素个数，容量（capacity）是当前方案允许保存的最多元素数。“空”表示size为0；“满”取决于容量或存储方案。空容器仍可以占有底层数组或头结点内存。数组中存在旧数据，也不代表这些位置仍属于有效队列。

长度为N的固定数组顺序栈可以保存N个元素；SQ09保留一个空位的循环队列只能保存N-1个。它们都使用数组，但访问规则和空满判定不同。不能把物理数组长度、逻辑元素个数、可用容量混为一个数。

### SQ01.5 读取、删除和操作的前置条件

查看栈顶或队头只读取，不改变元素数；出栈或出队会删除有效元素。操作的前置条件是执行前必须满足的要求：例如读取和删除要求非空，固定容量插入要求未满。后置条件描述执行后的结果，例如成功出队后size减1，剩余元素相对次序不变。

空栈没有合法栈顶，空队列没有合法队头。不能用返回0表示通用的“没有元素”，因为0本身可能是有效数据。可以采用异常、布尔值加输出参数、或`std::optional`等约定；本文手写结构用异常，标准库示例则由调用者先判空，不擅自假设标准库会代为抛出同样的异常。

### SQ01.6 C++赋值、比较与自增

`a = b`把b的值赋给a；`a == b`比较两者是否相等，不修改a。`rear = front = N - 1`是从右向左的赋值，最终两个变量都为N-1；它不是比较。`if (front = rear)`在语法上可能成立，却改变了front，因而通常是判空代码中的错误。

`++top`先增加top再使用新值，`top++`先产生旧值再增加top。因此在SQ05约定下，`data[++top] = x`先把空栈的top从-1变为0，再写入第一个位置；`return data[top--]`读取原栈顶后再降低top。必须先判空或判满，不能靠自增写法代替边界检查。

### SQ01.7 取模与循环下标

对于非负整数i和正整数N，`(i + 1) % N`把N-1之后的位置映射回0。例如N=5时，0、1、2、3、4的后继依次是1、2、3、4、0。“循环数组”是下标使用方式形成循环，不是把物理内存首尾焊接起来，也不会自动扩容。

C++的`%`是余数运算，负被除数可能得到负余数，所以计算循环队列长度时使用`(rear - front + N) % N`，而不是直接用`(rear - front) % N`。在合法下标0到N-1的前提下，加N可保证被除数非负；N必须大于0，不能对0取余。

### SQ01.8 头结点、首元结点、头指针与尾指针

头指针是指向链表起始位置的指针变量；头结点是可选的辅助结点，通常不保存有效数据；首元结点才是第一个有效数据结点。带头结点的链表可以让头指针指向头结点，首元结点位于其next位置。不带头结点时，头指针通常直接指向首元结点，空时可为nullptr。

本文链栈不带头结点，top指向有效栈顶；链队列带头结点，front始终指向辅助头结点。维护rear指向尾结点，可以避免每次入队都从头遍历；但删除最后有效结点后必须恢复空队列状态。头结点是实现选择，不是所有栈和队列ADT都强制要求的对象。

### SQ01.9 时间复杂度、空间复杂度与均摊

时间复杂度描述输入规模增大时基本操作次数的增长趋势。O(1)表示不随规模增长，不保证任何机器上都是相同毫秒数；O(n)表示线性级别，O(n²)表示平方级别。空间复杂度还要说明是否计算输入、输出，以及只计算额外辅助空间还是整个结构占用。

最坏复杂度分析一次操作在最不利情况下的代价；均摊分析把一串操作的总代价分摊到每次操作，不需要假设输入随机。例如动态数组偶尔扩容、两栈队列偶尔集中转移，单次可能O(n)，但按相应策略连续执行可以均摊O(1)。均摊复杂度与对随机输入求平均复杂度是不同概念。

### SQ01.10 不变量与数据结构栈的边界

不变量是每次对外操作开始和成功结束时都应成立的结构规则。例如SQ05有`-1 <= top < N`且size=top+1；SQ09有合法下标、容量N-1及约定的队头位置；SQ13空队列时front与rear都指向头结点。调试时应逐步检查这些规则，而不是只看最后一次打印结果。

数据结构中的“栈”是一种LIFO访问规则；程序运行时的“调用栈”是管理函数调用状态的一种机制；C++对象的自动存储期、动态存储期又是另一层概念。它们相关但不能等同。一个用`new`申请结点的链栈，仍然是栈ADT；不能因为结点来自动态内存就说它“不是栈”。

## SQ02 栈：栈顶、栈底与后进先出

栈（stack）是一种只允许在栈顶插入和删除元素的线性结构，也在栈顶读取元素。栈底是另一端。入栈`push(x)`把新元素放到栈顶；出栈`pop()`删除栈顶；查看栈顶`top/peek`读取但不删除。栈遵循后进先出LIFO：最近一次尚未出栈的入栈元素最先离开。

例如从空栈依次入栈A、B、C，并且三次入栈全部完成后才连续出栈，出栈顺序是C、B、A。若允许入栈、出栈交错，结果不一定是完整逆序：入A、出A、入B、出B、入C、出C也是合法操作。

对于入栈顺序1、2、3，出栈顺序3、1、2不可能：先取出3时，1仍被2压住。栈只能弹出顶部，不能跳过2先取1。判断出栈序列是否合法，可模拟入栈直到栈顶等于待输出元素，随后出栈；若无法匹配则不合法。

## SQ03 栈适合解决什么问题

当任务要求“最近开始、尚未完成的工作先结束”，通常可以考虑栈。例如括号匹配需要先匹配最内层左括号；深度优先搜索需要继续探索最近发现的分支；表达式求值需要保存尚不能计算的运算或中间结果。

浏览器后退可以用历史栈作简化模型；若同时实现前进，一般还需要前进栈及新访问时清空前进历史。编辑器撤销也可以用栈保存操作，但一次撤销如何恢复内容仍需定义逆操作或状态快照，栈本身不会自动提供这些信息。

## SQ04 C++标准库栈：读取与删除是两步

`std::stack<int>`是容器适配器，默认底层容器为`std::deque<int>`。`push`入栈，`top`返回栈顶引用，`pop`只删除且返回`void`。想“取出并返回”时，先复制`top()`，再`pop()`。空栈不可调用`top()`或`pop()`。接口依据：[C++标准工作草案 stack.defn](https://eel.is/c++draft/stack.defn)。本文只使用C++17已有接口。

### C01 标准库栈完整程序

```cpp
#include <cassert>
#include <stack>

int main() {
    std::stack<int> s;
    assert(s.empty());
    s.push(10);
    s.push(20);
    assert(s.top() == 20 && s.size() == 2);
    int removed = s.top();
    s.pop();
    assert(removed == 20 && s.top() == 10);
    s.pop();
    assert(s.empty());
}
```

## SQ05 顺序栈：top表示栈顶下标

本节固定数组顺序栈中，`top`表示栈顶元素的下标，空栈为`top == -1`。数组长度为N时，栈满为`top == N - 1`，元素数为`top + 1`。入栈先检查满，再使`top`加1并写入；出栈先检查空，再读出并使`top`减1。这里数组全部N个位置均可用，不采用循环队列的“保留一个空位”规则。

固定数组顺序栈的入栈、出栈、取顶、判空都是O(1)，空间O(N)。换用可扩容动态数组时，扩容需要搬移元素，单次入栈最坏O(n)，按几何倍数扩容时均摊O(1)，不能把均摊误说成每次都恒定。

### C02 固定数组顺序栈完整程序

```cpp
#include <array>
#include <cassert>
#include <stdexcept>

class ArrayStack {
    std::array<int, 3> data{};
    int top = -1;
public:
    bool empty() const { return top == -1; }
    bool full() const { return top == 2; }
    int size() const { return top + 1; }
    void push(int x) {
        if (full()) throw std::overflow_error("stack full");
        data[++top] = x;
    }
    int peek() const {
        if (empty()) throw std::underflow_error("stack empty");
        return data[top];
    }
    int pop() {
        if (empty()) throw std::underflow_error("stack empty");
        return data[top--];
    }
};

int main() {
    ArrayStack s;
    s.push(1); s.push(2); s.push(3);
    assert(s.full() && s.size() == 3);
    bool overflow = false;
    try { s.push(4); } catch (const std::overflow_error&) { overflow = true; }
    assert(overflow && s.size() == 3);
    assert(s.pop() == 3 && s.pop() == 2 && s.pop() == 1);
    bool underflow = false;
    try { s.pop(); } catch (const std::underflow_error&) { underflow = true; }
    assert(underflow && s.empty());
}
```

## SQ06 链栈：链表头部作为栈顶

本节链栈不带头结点，`top`直接指向第一个有效结点，空栈为`top == nullptr`。入栈申请新结点，将它的`next`指向旧栈顶，再更新`top`；出栈保存旧结点与数据，让`top`指向后继，再释放旧结点。表头操作不需要遍历，算法步骤为O(1)。

链栈无需预先固定容量，但不能说“永远不会满”：申请内存可能失败。以下类拥有结点，析构时释放，禁止复制和移动，避免默认浅拷贝导致重复释放。为保持示例简洁只存储`int`，不讨论任意类型构造、拷贝异常。

### C03 无头结点链栈完整程序

```cpp
#include <cassert>
#include <stdexcept>

class LinkedStack {
    struct Node { int value; Node* next; };
    Node* top = nullptr;
public:
    LinkedStack() = default;
    LinkedStack(const LinkedStack&) = delete;
    LinkedStack& operator=(const LinkedStack&) = delete;
    LinkedStack(LinkedStack&&) = delete;
    LinkedStack& operator=(LinkedStack&&) = delete;
    ~LinkedStack() {
        while (top) { Node* p = top; top = top->next; delete p; }
    }
    bool empty() const { return top == nullptr; }
    void push(int x) { top = new Node{x, top}; }
    int peek() const {
        if (empty()) throw std::underflow_error("stack empty");
        return top->value;
    }
    int pop() {
        if (empty()) throw std::underflow_error("stack empty");
        Node* p = top;
        int x = p->value;
        top = p->next;
        delete p;
        return x;
    }
};

int main() {
    LinkedStack s;
    s.push(7); s.push(9);
    assert(s.peek() == 9 && s.pop() == 9 && s.pop() == 7);
    assert(s.empty());
    s.push(11);
    assert(s.peek() == 11);
}
```

## SQ07 队列：队头、队尾与先进先出

队列（queue）是一种在队尾插入，在队头删除的线性结构，普通队列遵循先进先出FIFO。`enqueue`表示入队，`dequeue`表示出队，`front/peek`表示读取队头而不删除。队尾是最新到达的位置，队头是下一次要服务的位置。优先队列按优先级取出，不能与普通FIFO队列混为一谈。

例如从空队列依次入队A、B、C，再连续出队，顺序为A、B、C。入队A、B，出队A，再入队C，此时从队头到队尾为B、C；已经出队的A不应继续计入队列。

排队打印是FIFO的典型简化场景：在不考虑优先级、插队、取消等额外策略时，先提交的任务先服务。若问题包含加急任务，应先问清调度规则，不能仅凭“打印任务”四个字就断定FIFO完全适用。

## SQ08 C++标准库队列与假溢出

`std::queue<int>`默认以`std::deque<int>`为底层容器。`push`队尾入队，`front`读取队头，`back`读取队尾，`pop`只删除队头并返回`void`。取元素前先判空。接口依据：[C++标准工作草案 queue.defn](https://eel.is/c++draft/queue.defn)。

若用数组实现普通顺序队列，出队只将队头位置向后移动、入队只向更高下标写入，那么低下标虽已腾空，队尾到达数组末尾后仍可能无法入队，这叫假溢出。解决方法包括搬移元素、循环复用空间、改用链队列。每次搬移可能O(n)，循环队列无需每次整体搬移。

### C04 标准库队列完整程序

```cpp
#include <cassert>
#include <queue>

int main() {
    std::queue<int> q;
    q.push(10); q.push(20);
    assert(q.front() == 10 && q.back() == 20);
    int removed = q.front();
    q.pop();
    q.push(30);
    assert(removed == 10 && q.front() == 20 && q.back() == 30);
    q.pop(); q.pop();
    assert(q.empty());
}
```

## SQ09 循环队列的统一约定与公式

本知识库的主实现采用以下约定A：底层数组长度`QueueSize = N`且`N >= 2`；`front`指向队头元素的前一个位置，`rear`指向队尾元素；浪费一个数组元素空间以区分空和满。空队列初始化为`front = rear = N - 1`。因此队头元素位于`data[(front + 1) % N]`，不能直接读`data[front]`。

在约定A并保留一个空位的前提下，队空为`front == rear`；队满的条件是：(rear + 1) % QueueSize == front。最多存储N-1个元素。当前元素个数为`(rear - front + N) % N`。这些公式必须与上述指针含义一起使用。

循环队列入队：先判满，未满时执行`rear = (rear + 1) % QueueSize`，再写`data[rear] = x`。循环队列出队：先判空，非空时执行`front = (front + 1) % QueueSize`，再返回`data[front]`。读取队头只读下一位置，不修改指针。

取模使下标N-1的下一个位置回到0。初始化使用`front = rear = N - 1`是赋值；`front == rear`是比较。C++条件误写`front = rear`会修改状态，不能替代判空。数学文字中的等号不能机械照抄为C++赋值表达式。

## SQ10 循环队列的计算与完整过程

以下推演均采用SQ09约定A，数组长度N=5，可用容量4，初始`front = rear = 4`。表中内容按队头到队尾排列，已删除位置即使仍有旧数值，也不属于有效队列。

| 操作 | front | rear | 有效队列 | 状态 |
|---|---|---|---|---|
| 初始化 | 4 | 4 | 空 | 空 |
| 入队A | 4 | 0 | A | 非空、未满 |
| 入队B | 4 | 1 | A、B | 未满 |
| 入队C | 4 | 2 | A、B、C | 未满 |
| 出队一次，返回A | 0 | 2 | B、C | 未满 |
| 入队D | 0 | 3 | B、C、D | 未满 |
| 入队E | 0 | 4 | B、C、D、E | 满 |

最后`(rear + 1) % 5 = 0 = front`，因此队满；再入队应报告上溢，不能覆盖B。当前元素数为`(4 - 0 + 5) % 5 = 4`。

另一例：N=8、front=6、rear=2时，元素数是`(2-6+8)%8=4`，有效下标为7、0、1、2，容量为7。只知道这些下标和指针，不能推断里面具体保存了哪些值。必须给出初始内容或完整操作序列，才能回答队列内容。

## SQ11 循环队列的完整C++实现

以下`CircularQueue`使用SQ09约定A，`enqueue/dequeue/head`均先检查边界。固定容量下每个基本操作O(1)，空间O(N)。构造函数额外限制数组长度不超过100000，避免教学示例中的整数运算与不合理分配；这不是循环队列的理论上限。

### C05 保留一个空位的循环队列完整程序

```cpp
#include <cassert>
#include <stdexcept>
#include <vector>

class CircularQueue {
    int QueueSize;
    std::vector<int> data;
    int front, rear;
    static int checked(int n) {
        if (n < 2 || n > 100000) throw std::invalid_argument("invalid array size");
        return n;
    }
public:
    explicit CircularQueue(int n)
        : QueueSize(checked(n)), data(QueueSize), front(QueueSize - 1), rear(front) {}
    bool empty() const { return front == rear; }
    bool full() const { return (rear + 1) % QueueSize == front; }
    int size() const { return (rear - front + QueueSize) % QueueSize; }
    int capacity() const { return QueueSize - 1; }
    void enqueue(int x) {
        if (full()) throw std::overflow_error("queue full");
        rear = (rear + 1) % QueueSize;
        data[rear] = x;
    }
    int dequeue() {
        if (empty()) throw std::underflow_error("queue empty");
        front = (front + 1) % QueueSize;
        return data[front];
    }
    int head() const {
        if (empty()) throw std::underflow_error("queue empty");
        return data[(front + 1) % QueueSize];
    }
};

int main() {
    CircularQueue q(5);
    q.enqueue(1); q.enqueue(2); q.enqueue(3);
    assert(q.dequeue() == 1);
    q.enqueue(4); q.enqueue(5);
    assert(q.full() && q.size() == 4 && q.head() == 2);
    bool overflow = false;
    try { q.enqueue(6); } catch (const std::overflow_error&) { overflow = true; }
    assert(overflow && q.head() == 2);
    for (int x : {2, 3, 4, 5}) assert(q.dequeue() == x);
    assert(q.empty());
    bool underflow = false;
    try { q.head(); } catch (const std::underflow_error&) { underflow = true; }
    assert(underflow);
}
```

## SQ12 进阶：其他循环队列约定与满容量方案

另一种常见约定B使用`head`指向队头元素本身，`tail`指向下一次写入位置，并保留一个空位。此时先写`data[tail]`再推进tail，先读`data[head]`再推进head。空为`head == tail`，满为`(tail + 1) % N == head`，队头是`data[head]`。B与A的满空公式形式相似，但读写位置及执行先后不同，不能拼接两套代码。

若另外维护元素计数`count`，可以使用全部N个位置：空为`count == 0`，满为`count == N`，入队使count加1，出队使count减1。也可以增加满标记来区分同样的指针位置。不要把这些方案的容量N误套到SQ09的容量N-1，也不要只凭两个同名变量就断定公式通用。

数组队列如何处理循环复用与扩容，可对照[Cornell CS2110 Stacks and Queues](https://www.cs.cornell.edu/courses/cs2110/2026sp/lectures/lec15/)。该课程的队头、下一写入位置定义与本文约定A不同；本文SQ09—SQ11的主实现以约定A为准。

## SQ13 带头结点的链队列与最后一个结点

本节链队列带一个不保存有效元素的头结点。队头指针指向链队列的头结点，`rear`指向最后一个有效结点；空队列的`rear == front`，二者都指向头结点。第一个有效元素是`front->next`，不能把头结点本身当作有效数据。

入队在尾部接入新结点并更新rear。出队删除`front->next`，头结点本身保留。若删除的是最后一个有效结点，必须使`rear = front`；否则rear可能指向已经释放的结点，形成悬空指针，下一次入队访问它会出错。不带头结点的另一种实现可能在空时令两个指针都为nullptr，不能混用。

链队列持有头尾指针时，入队、出队、取队头的算法步骤都是O(1)，空间O(n)。它按需申请结点，仍可能内存不足；每个结点额外保存指针，缓存局部性通常不如连续数组。

### C06 带头结点链队列完整程序

```cpp
#include <cassert>
#include <stdexcept>

class LinkedQueue {
    struct Node { int value; Node* next; };
    Node* front;
    Node* rear;
public:
    LinkedQueue() : front(new Node{0, nullptr}), rear(front) {}
    LinkedQueue(const LinkedQueue&) = delete;
    LinkedQueue& operator=(const LinkedQueue&) = delete;
    LinkedQueue(LinkedQueue&&) = delete;
    LinkedQueue& operator=(LinkedQueue&&) = delete;
    ~LinkedQueue() {
        while (front) { Node* p = front; front = front->next; delete p; }
    }
    bool empty() const { return rear == front; }
    void enqueue(int x) {
        Node* s = new Node{x, nullptr};
        rear->next = s;
        rear = s;
    }
    int head() const {
        if (empty()) throw std::underflow_error("queue empty");
        return front->next->value;
    }
    int dequeue() {
        if (empty()) throw std::underflow_error("queue empty");
        Node* p = front->next;
        int x = p->value;
        front->next = p->next;
        if (p->next == nullptr) rear = front;
        delete p;
        return x;
    }
};

int main() {
    LinkedQueue q;
    q.enqueue(5);
    assert(q.head() == 5 && q.dequeue() == 5 && q.empty());
    q.enqueue(8); q.enqueue(9);
    assert(q.dequeue() == 8 && q.head() == 9);
    assert(q.dequeue() == 9 && q.empty());
    bool underflow = false;
    try { q.dequeue(); } catch (const std::underflow_error&) { underflow = true; }
    assert(underflow);
}
```

## SQ14 存储结构和复杂度对比

下面分析固定数组、正常维护头尾指针的单链结构，以及按几何倍数扩容的动态数组；“基本操作”指入栈/出栈/取顶或入队/出队/取头。空间包含数据本身。

| 实现 | 关键操作时间 | 空间与容量 | 主要注意点 |
|---|---|---|---|
| 固定数组顺序栈 | 每次O(1) | O(N)，容量N | 栈满检查 |
| 动态数组栈 | push最坏O(n)、均摊O(1)；取顶/弹出O(1) | O(n)，通常有预留空间 | 扩容成本 |
| 链栈，表头为栈顶 | 算法步骤O(1) | O(n)，每结点有指针 | 释放与所有权 |
| 固定循环队列，约定A | 每次O(1) | O(N)，容量N-1 | 不能混用其他下标定义 |
| 带头结点链队列 | 算法步骤O(1) | O(n)，额外一个头结点 | 删除最后有效结点时重置rear |
| 出队后整体搬移的数组队列 | 出队O(n) | O(N) | 与循环队列不同 |

容量确定且希望连续存储，可以考虑固定数组；规模变化大，可考虑动态数组或链结构。链结构不是在所有机器上都更快，实际性能还受分配、缓存与工作负载影响。

## SQ15 栈应用：括号匹配

括号匹配维护“尚未匹配的左括号”栈。读到左括号入栈；读到右括号时，栈顶必须是对应的左括号，然后弹出；扫描结束栈还须为空。仅比较左右括号数量不够，例如`([)]`数量相等但嵌套错误。长度为n时，时间O(n)，额外空间最坏O(n)。

以下示例只识别`()[]{}`，忽略其他字符，不解析字符串字面量和注释。因此它适合算法练习，不是完整C++语法检查器。

### C07 三种括号匹配完整程序

```cpp
#include <cassert>
#include <string>
#include <vector>

bool balanced(const std::string& text) {
    std::vector<char> s;
    for (char c : text) {
        if (c == '(' || c == '[' || c == '{') s.push_back(c);
        else if (c == ')' || c == ']' || c == '}') {
            char wanted = c == ')' ? '(' : c == ']' ? '[' : '{';
            if (s.empty() || s.back() != wanted) return false;
            s.pop_back();
        }
    }
    return s.empty();
}

int main() {
    assert(balanced("a + (b * [c + d])"));
    assert(balanced(""));
    assert(!balanced("([)]"));
    assert(!balanced(")("));
    assert(!balanced("(()"));
}
```

## SQ16 栈应用：后缀表达式和操作数顺序

中缀表达式`(2 + 3) * 4`对应后缀表达式`2 3 + 4 *`。后缀表达式不需要用括号表达运算优先关系：遇数入栈，遇二元运算符先弹右操作数b，再弹左操作数a，计算`a op b`后入栈。`8 3 -`结果是5，不能算成3-8。

把中缀转后缀还需要运算符栈：按优先级与结合性决定何时弹出；左括号入栈，右括号触发弹出直到对应左括号。若加入一元负号或幂运算，必须重新定义词法和结合性，不能直接沿用仅含二元加减乘除的规则。

下面计算器的输入以空白分隔，支持有符号十进制整数及二元`+ - * /`。使用C++整数除法（向0截断）。每个输入与中间结果限定在±1000000000；乘法暂存至`long long`，因两操作数均受界限约束，其乘积不超过10^18，随后再次检查界限。除0、非法词法、操作数不足及剩余多个结果均报错。时间O(n)指总输入字符数线性、整数长度有界。

### C08 有界后缀表达式求值完整程序

```cpp
#include <cassert>
#include <sstream>
#include <stdexcept>
#include <string>
#include <vector>

long long bounded(long long x) {
    if (x < -1000000000LL || x > 1000000000LL)
        throw std::overflow_error("numeric bound exceeded");
    return x;
}

long long postfix(const std::string& expression) {
    std::istringstream input(expression);
    std::vector<long long> s;
    std::string token;
    while (input >> token) {
        if (token == "+" || token == "-" || token == "*" || token == "/") {
            if (s.size() < 2) throw std::invalid_argument("missing operand");
            long long b = s.back(); s.pop_back();
            long long a = s.back(); s.pop_back();
            if (token == "/" && b == 0) throw std::domain_error("division by zero");
            long long x = token == "+" ? a + b : token == "-" ? a - b
                        : token == "*" ? a * b : a / b;
            s.push_back(bounded(x));
        } else {
            std::size_t used = 0;
            long long x = std::stoll(token, &used, 10);
            if (used != token.size()) throw std::invalid_argument("invalid integer");
            s.push_back(bounded(x));
        }
    }
    if (s.size() != 1) throw std::invalid_argument("invalid final stack");
    return s.back();
}

int main() {
    assert(postfix("2 3 + 4 *") == 20);
    assert(postfix("8 3 -") == 5);
    assert(postfix("-7 2 /") == -3);
    bool zero = false;
    try { postfix("3 0 /"); } catch (const std::domain_error&) { zero = true; }
    assert(zero);
    bool invalid = false;
    try { postfix("1 +"); } catch (const std::invalid_argument&) { invalid = true; }
    assert(invalid);
}
```

## SQ17 栈应用：递归与深度优先搜索DFS

递归函数调用需要保存返回位置、局部状态等信息，可以把这种“暂停外层、先完成内层”的行为理解为调用栈。递归深度过大会耗尽可用调用栈空间，具体上限由语言运行时、系统与函数帧大小决定，并不是算法统一规定的数字。

将递归DFS改成迭代DFS，需要显式栈保存待处理顶点或调用帧。若要严格重现递归的访问和回退顺序，可能需要同时保存当前邻接位置，而不是简单反转邻接表就保证所有图上完全一致。带环图应维护访问状态，避免无限重复。

栈适合深度优先；队列适合广度优先。普通DFS不保证无权图的最少边数路径；不能因为找到了路径就称为最短路径。

## SQ18 队列应用：BFS与无权最短路径

广度优先搜索BFS使用FIFO队列按距离层次处理顶点。对无权图或所有边权相同且为正的图，首次发现顶点的路径具有最少边数。应在顶点入队时标记或设置距离，避免同一顶点被多个前驱重复入队。

邻接表BFS时间O(V+E)，额外距离数组和队列空间O(V)，不包含输入图。不可达顶点的距离可以记为-1。边权不同的一般最短路不能直接套普通BFS；0/1边权可以使用专门的0-1 BFS，非负一般边权通常考虑Dijkstra等算法。可对照[CP-Algorithms BFS](https://cp-algorithms.com/graph/breadth-first-search.html)。

以下程序使用有向邻接表，顶点编号0到V-1。无向图需在两个方向均添加边。程序检查起点和所有端点编号，不接受越界顶点。

### C09 无权图BFS完整程序

```cpp
#include <cassert>
#include <queue>
#include <stdexcept>
#include <vector>

std::vector<int> bfs(const std::vector<std::vector<int>>& graph, int source) {
    int n = static_cast<int>(graph.size());
    if (source < 0 || source >= n) throw std::invalid_argument("invalid source");
    for (const auto& row : graph)
        for (int v : row)
            if (v < 0 || v >= n) throw std::invalid_argument("invalid endpoint");
    std::vector<int> distance(n, -1);
    std::queue<int> q;
    distance[source] = 0;
    q.push(source);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : graph[u]) {
            if (distance[v] != -1) continue;
            distance[v] = distance[u] + 1;
            q.push(v);
        }
    }
    return distance;
}

int main() {
    std::vector<std::vector<int>> graph = {{1, 2}, {3}, {3}, {4}, {}, {}};
    assert((bfs(graph, 0) == std::vector<int>{0, 1, 1, 2, 3, -1}));
    assert((bfs({{0}}, 0) == std::vector<int>{0}));
}
```

## SQ19 进阶：用两个栈实现队列与均摊分析

维护输入栈`in`和输出栈`out`。入队压入in；取队头或出队时，若out非空，直接使用其顶部；只有out为空时，才把in逐个弹出并压入out。两次逆序使最早入队的元素位于out顶部。out仍有元素时不能随意将in倒入，否则会破坏FIFO。

某次转移可能搬动n个元素，单次出队最坏O(n)。但一串操作中，每个元素至多经历一次压入in、一次从in弹出并压入out、一次从out弹出，所以m次操作的总栈操作数O(m)，均摊每次O(1)。这不是“每次最坏O(1)”，也不是“不需要额外空间”；保存n个元素需要O(n)空间。两个栈构造队列的思想可对照[Minimum Stack / Minimum Queue](https://cp-algorithms.com/data_structures/stack_queue_modification.html)。

### C10 两栈队列完整程序

```cpp
#include <cassert>
#include <stack>
#include <stdexcept>

class TwoStackQueue {
    std::stack<int> in, out;
    void transfer() {
        if (!out.empty()) return;
        while (!in.empty()) { out.push(in.top()); in.pop(); }
    }
public:
    bool empty() const { return in.empty() && out.empty(); }
    void enqueue(int x) { in.push(x); }
    int head() {
        transfer();
        if (out.empty()) throw std::underflow_error("queue empty");
        return out.top();
    }
    int dequeue() {
        int x = head();
        out.pop();
        return x;
    }
};

int main() {
    TwoStackQueue q;
    q.enqueue(1); q.enqueue(2);
    assert(q.dequeue() == 1);
    q.enqueue(3);
    assert(q.dequeue() == 2 && q.dequeue() == 3 && q.empty());
    bool underflow = false;
    try { q.dequeue(); } catch (const std::underflow_error&) { underflow = true; }
    assert(underflow);
}
```

## SQ20 进阶：最小栈与重复最小值

最小栈在普通栈之外支持读取当前最小值。可以让每个栈位置同时记录“该位置以下所有元素的最小值”。新入x时，记录`min(x, 旧最小值)`；出栈同时删除该条记录。即使重复最小值入栈，例如3、1、1，弹出一个1后最小值仍为1。

本节使用`vector<pair<int,int>>`：取顶、取最小和弹出O(1)，push因动态扩容最坏O(n)、均摊O(1)，空间O(n)。若使用同步辅助最小栈的另一种写法，只记录新最小时要妥善处理相等值，不能漏掉重复最小值的恢复。

### C11 保存前缀最小值的最小栈完整程序

```cpp
#include <algorithm>
#include <cassert>
#include <stdexcept>
#include <utility>
#include <vector>

class MinStack {
    std::vector<std::pair<int, int>> data;
public:
    bool empty() const { return data.empty(); }
    void push(int x) {
        int minimum = empty() ? x : std::min(x, data.back().second);
        data.emplace_back(x, minimum);
    }
    int minValue() const {
        if (empty()) throw std::underflow_error("stack empty");
        return data.back().second;
    }
    int pop() {
        if (empty()) throw std::underflow_error("stack empty");
        int x = data.back().first;
        data.pop_back();
        return x;
    }
};

int main() {
    MinStack s;
    s.push(3); s.push(1); s.push(1);
    assert(s.minValue() == 1);
    assert(s.pop() == 1 && s.minValue() == 1);
    assert(s.pop() == 1 && s.minValue() == 3);
    assert(s.pop() == 3 && s.empty());
}
```

## SQ21 进阶：单调栈与下一个更大元素

单调栈保存按值满足单调关系的候选位置，常用于“左侧/右侧第一个更大或更小元素”。下面求每个位置右侧第一个严格更大元素的下标：从左到右扫描，栈保存尚未找到答案的下标；新值比栈顶值大时，栈顶的答案就是当前位置并弹出，再继续比较。

这里使用严格小于`a[stack.back()] < a[i]`触发弹出，相等元素不会被当作“更大”。每个下标只入栈一次、出栈至多一次，虽然有嵌套循环，总时间O(n)，额外空间O(n)。返回-1表示不存在对应下标。

### C12 右侧第一个严格更大元素完整程序

```cpp
#include <cassert>
#include <vector>

std::vector<int> nextGreaterIndex(const std::vector<int>& a) {
    std::vector<int> answer(a.size(), -1), s;
    for (int i = 0; i < static_cast<int>(a.size()); ++i) {
        while (!s.empty() && a[s.back()] < a[i]) {
            answer[s.back()] = i;
            s.pop_back();
        }
        s.push_back(i);
    }
    return answer;
}

int main() {
    assert((nextGreaterIndex({2, 1, 2, 4, 3}) == std::vector<int>{3, 2, 3, -1, -1}));
    assert((nextGreaterIndex({2, 2}) == std::vector<int>{-1, -1}));
    assert(nextGreaterIndex({}).empty());
}
```

## SQ22 进阶：单调队列与滑动窗口最大值

长度为k的窗口每次向右移动一格，要求窗口最大值。使用双端队列保存候选元素的下标，保持对应值从前到后严格递减：先移除已经离开窗口的队首下标，再从队尾移除值小于等于新值的下标，最后加入新下标。队首始终是当前窗口的最大值位置。

移除旧候选的理由是：新元素更大或相等、且更晚过期，旧候选不可能在将来的窗口中优于它。保存下标才能正确处理过期与重复值。每个下标至多入队一次、从两端总共删除一次，时间O(n)，辅助队列O(k)，输出额外O(n-k+1)。单调候选队列不是保存所有元素的普通FIFO队列。候选淘汰思路可对照[CP-Algorithms固定窗口极值](https://cp-algorithms.com/data_structures/stack_queue_modification.html#finding-the-minimum-for-all-subarrays-of-fixed-length)。

### C13 滑动窗口最大值完整程序

```cpp
#include <cassert>
#include <deque>
#include <stdexcept>
#include <vector>

std::vector<int> windowMax(const std::vector<int>& a, int k) {
    if (k <= 0 || k > static_cast<int>(a.size()))
        throw std::invalid_argument("invalid window");
    std::deque<int> candidates;
    std::vector<int> result;
    for (int i = 0; i < static_cast<int>(a.size()); ++i) {
        while (!candidates.empty() && candidates.front() <= i - k)
            candidates.pop_front();
        while (!candidates.empty() && a[candidates.back()] <= a[i])
            candidates.pop_back();
        candidates.push_back(i);
        if (i >= k - 1) result.push_back(a[candidates.front()]);
    }
    return result;
}

int main() {
    assert((windowMax({1, 3, -1, -3, 5, 3, 6, 7}, 3) == std::vector<int>{3, 3, 5, 5, 6, 7}));
    assert((windowMax({2, 2, 2}, 2) == std::vector<int>{2, 2}));
    assert((windowMax({-3}, 1) == std::vector<int>{-3}));
    bool invalid = false;
    try { windowMax({1}, 0); } catch (const std::invalid_argument&) { invalid = true; }
    assert(invalid);
}
```

## SQ23 进阶：双端队列、优先队列与并发边界

双端队列deque允许在两端插入和删除；普通队列只在队尾插入、队头删除。单调队列利用deque维护候选集合。优先队列按优先级取元素，一般不保证同优先级元素按先来顺序出队，除非额外规定稳定策略；它与FIFO队列不是同一ADT。

普通数组、链栈、链队列示例都没有线程同步，不能直接作为安全的多生产者/多消费者队列。并发队列还需要处理锁或原子操作、可见性、空满等待、取消和对象生命周期。仅把下标声明为`volatile`不等于完成同步。本资料不提供无锁队列的正确性保证，也不包含完整并发实现。

Python中可以用`list.append/pop`表示栈，用`collections.deque.append/popleft`表示FIFO队列。列表头部删除需要搬移后续元素，不适合作为高频出队的简单队列实现。参见[Python官方数据结构教程](https://docs.python.org/3/tutorial/datastructures.html#using-lists-as-queues)。

## SQ24 常见错误与纠正

| 错误说法或写法 | 正确理解 |
|---|---|
| 栈总会输出输入的逆序 | 只有全部入栈后再连续出栈才必然整体逆序；交错操作须模拟 |
| 队列在队头插入、队尾删除 | 本文FIFO队列在队尾入队、队头出队 |
| 数组长度N的循环队列都能存N个元素 | SQ09保留一个空位，容量N-1；计数等方案可用N个位置 |
| front一定指向有效队头元素 | SQ09指向队头前一位置，SQ12约定B才指向队头本身 |
| `if (front = rear)`判空 | 这是赋值；本实现比较要写`front == rear` |
| 取队头也要推进front | 取队头只读取；出队才修改队列 |
| 带头结点链队列删除最后元素后rear不变 | rear必须回到头结点，避免悬空指针 |
| 链式结构无限容量 | 仍受内存限制且分配可能失败 |
| C++ `s.pop()`或`q.pop()`返回元素 | 标准库版本返回void，先top/front再pop |
| 代码有两层循环所以必然O(n²) | 单调结构需按总入栈/出栈次数分析，可为O(n) |
| BFS求任意边权图的最短路 | 普通BFS适用无权或等正权最少边数问题 |
| 两栈队列每次出队最坏O(1) | 转移时最坏O(n)，连续操作均摊O(1) |

## SQ26 自测题与解析

### SQ26.1 后进先出与先进先出

题：A、B、C全部入栈后再全部出栈；另一个空队列依次入队A、B、C后再全部出队，各是什么顺序？答：栈为C、B、A，队列为A、B、C。前提是题中明确“全部入栈后”，不能推广到任意交错操作。

### SQ26.2 队列容量和元素数

题：按约定A，数组长度为10，front=7、rear=2，当前多少元素，最多能放多少？答：当前`(2-7+10)%10=5`个，最多9个；队列中具体数值无法由这两个下标确定。

### SQ26.3 判断队满

题：按约定A，N=6、front=2、rear=1，还能否入队？答：`(1+1)%6=2=front`，已经队满，容量5，不能继续合法入队。不能因为rear小于front就判断未满。

### SQ26.4 删除唯一结点

题：带头结点链队列仅有一个有效结点，删除后front与rear在哪里？答：front保留指向头结点，头结点next变为nullptr，rear重新指向front；被删除的有效结点释放。

### SQ26.5 取队头和出队

题：循环队列head与dequeue都返回队头，为什么不是同一操作？答：约定A中head读取`data[(front+1)%N]`并保持状态；dequeue先移动front再返回元素，元素数减少1。两者都必须先检查非空。

### SQ26.6 空栈与非法括号

题：`([)]`左右括号数量相同，是否匹配？答：不匹配。扫描到`)`时栈顶是`[`，类型不符；数量相同不代表嵌套正确。

### SQ26.7 运算数顺序

题：后缀`10 4 - 2 /`的结果是什么？答：先算10-4=6，再算6/2=3；弹出的第一个数是右操作数，不能把减法写反。

### SQ26.8 均摊与最坏

题：两栈队列的一次出队能否搬动很多元素？答：能。输出栈为空时可能搬动所有输入元素，所以单次最坏O(n)；每个元素只跨栈一次，连续操作均摊O(1)。

### SQ26.9 单调结构与重复值

题：求“严格更大”时，相同值应当当作答案吗？答：不应。SQ21只在新值严格大于旧值时确定答案。滑动窗口最大值的候选淘汰则可删除较早的相同值，因为新值更晚过期；两个问题的等号策略不应混用。

### SQ26.10 信息不足的题

题：循环队列front=2、rear=4，队列内容是什么？答：信息不足。还缺数组长度、指针约定与实际元素或完整操作记录。即使补充长度和约定后算出了元素个数，也不能凭下标猜出元素值。
