# 栈与队列 Markdown 教材

知识库正文为 **栈与队列知识库.md**，版本1.1。包括28个主主题、10个基础补课小节、10道自测解析及13个独立C++17完整程序。内容覆盖ADT、逻辑与存储、下标与指针、容量、取模、复杂度、顺序栈/链栈、循环队列/链队列、括号、表达式、BFS、两栈队列、最小栈与单调结构。正文末尾列出已核对的公开原始资料链接。

这是重新编写的学习材料，不是扫描教材的逐页转录。循环队列主约定为front指向队头前一个位置、rear指向队尾、保留一个空位；其他约定独立说明。代码及运算假定明确列出，不能把本文件的章节号伪称为旧PDF页码。

## 在现有项目中使用

实际项目知识库「栈与队列（文字与代码）」已启用此MD及对应Qwen文本向量；旧PDF归档保留。刷新网页并使用原账号登录，进入该知识库的课程资料，选择MD后点击「基于此资料问答」。代码可直接在原文中查看。

MD本身无需OCR，不使用MinerU。现有Python解析器按标题结构定位，段落、表格、代码分别处理；完整代码块保持完整，引用使用章节标题与真实字符偏移。Qwen3-VL-Embedding-2B在本方案中只接收文字，生成2048维向量；MiMo依据检索片段生成并核对答案。图像向量和图片理解暂不启用。

主程序、SQLite、FileStore、后台队列及模型配置均复用原项目。178个片段所需12次小批量向量请求超过原单任务10次上限，本机已将`AI_RUN_MAX_MODEL_CALLS`设为16。原API密钥和其他配置保留。该调用数上限不是费用上限；本轮2元验收另有共享费用预留账本。

## 校验与维护

从项目根目录运行 `python -m scripts.verify_stack_queue_material` 可从正文直接提取13个代码块，使用本机g++按C++17编译，运行示例及独立对照检查。包含随机队列/栈操作、括号递归语法识别、图最短路对照、单调结构朴素算法对照。生成文件位于忽略目录 `test-results/stack-queue-md/`，不调用模型。

本地导入脚本为 `python -m scripts.import_stack_queue_markdown --output test-results/stack-queue-md/dry-run.json`，默认仅在临时库检查。实际写入需要显式`--apply`、目标course-id，且主程序停止。导入需要与正文指纹匹配的代码验证回执，先验证引用，再归档显式指定的旧PDF；原件不删除。

修改正文后，应重新运行代码和检索检查，并解析新修订、重建或复用匹配文字的向量；不能沿用旧版本的引用ID。相同正文片段可复用同模型、同维度、同适配器的真实向量；新增或变化的文字才需要重新向量化。向量缓存导入需校验正文hash、模型身份、每个片段hash及完整覆盖；缓存不完整时禁止暗中转为网络调用。

`evals/rag/stack-queue-md.json`提供24条作者设计的证据定位检查和5种本地规则计算；`stack-queue-md-answers.json`提供生成回答的冒烟问题。它们不是独立人工盲测集。检索命中、原文引用有效、模型自审通过，都不能单独等同答案完全正确。
