# 数据结构与算法共享资料

本目录按用户本次明确要求，随 PR #14 提交课程原件与图片补录结果。它使团队成员拉取分支后可以在自己的学涯服务中建立相同课程知识库，无需复制任何人的私人数据库。

- `ppt/`：17份原始PPTX，总计44,433,210字节，1112页；没有修改原件，没有包含Office临时锁文件。
- `manifest.json`：文件相对路径、SHA-256、大小、章节、页数及预期片段数。
- `visual-reviews.json`：按文件hash和实际页码关联的视觉转写、图示说明、空白页核对及逐图分类；不含本机绝对路径、账号、课程/文档ID、密钥或私人学习记录。

图片原件已经嵌入PPT中，不另存重复图片包。补录包含前次3个图片页、4个空白页及本轮206页的追加内容；重建后的预期总数为1495个片段。

## 首次启动自动准备

下载完整仓库并启动 `backend.xueya.server`（Windows 双击“启动学涯.cmd”也使用同一入口），新数据目录会在后台将本资料包导入默认“数据结构”课程。网页立即可用；打开“知识库”可看到当前文件和完成份数，导入完成后自动更新资料列表，可直接检索原文。

重复启动不新增课程、文档或修订；正常中途停止后，下次启动会继续准备。资料缺失、校验失败或内容冲突会显示明确提示，修复文件后可点击“重试准备演示课件”，已完成资料保留。本流程只做本地解析和导入已有图片补录，不会请求模型、Embedding、OCR 或重排 API。

有任何文档历史（包括归档或删除过的文档）的数据目录不会自动添入演示资料。完成后手动修改或移除课件也不会因重启被恢复。可在 `.env` 中设置 `XUEYA_AUTO_IMPORT_DEMO=0` 禁用自动准备。

## 可选：手动导入

关闭自动准备，或需要向已有服务显式导入另一门课程时，先启动主服务，然后在项目根目录执行：

```powershell
.venv/Scripts/python.exe -m scripts.import_course_bundle --apply
```

默认连接 `http://127.0.0.1:4173`。此命令创建/复用独立的“数据结构与算法”课程；若要导入默认课程，可加 `--existing-course-id course-default`。自动准备已完成时无需再运行。此过程使用普通文本解析和已整理的图片转写，不需要PowerPoint、OCR密钥、GPU或付费模型调用。

只检查资料完整性、不连接服务及写入数据：

```powershell
.venv/Scripts/python.exe -m scripts.import_course_bundle
```

需要指定已存在的课程时，可加 `--existing-course-id <课程ID>`；服务端口不同则加 `--base-url http://127.0.0.1:<端口>`。只允许本机HTTP地址。重复执行会核对既有补录并跳过，不创建重复文档；如同一图片的已采纳内容与资料包不同，工具报冲突并保留现有内容，不静默覆盖。中途停止后可再次执行。操作报告默认写入不提交Git的 `test-results/course-bundle/import.json`。

macOS/Linux使用 `.venv/bin/python` 运行同一模块。导入期间不要同时重新解析、修改或归档目标课件；版本冲突会中止当前处理，已完成文档保留。

## 评委从下载到体验

1. 下载并解压完整仓库，按根目录 [README](../../README.md#启动) 安装依赖、启动主服务。Windows 可双击 `启动学涯.cmd`；macOS/Linux 在项目根目录运行以下命令，并保持服务终端打开：

   ```sh
   python3 -m venv .venv
   .venv/bin/python -m pip install -r requirements.lock
   .venv/bin/python -m backend.xueya.server
   ```

2. 无需运行导入命令。打开 `http://127.0.0.1:4173/#space/knowledge`，默认选择“数据结构”，等待“准备演示知识库”进度完成。全新课程预期为 **17 份资料、1112 页、1495 个片段**；可在处理中先查看已有资料，完整检索示例应在准备完成后体验。
3. 选择“关键词检索”，依次输入下表关键词，点击结果中的“核对原文”，查看实际页码及上下文。若端口有改动，请使用启动时实际显示的地址。已有数据目录不自动导入时，可按上面的可选手动步骤准备课程。

   | 输入关键词 | 应能检索到的相关课件 |
   | --- | --- |
   | 栈和队列 | 第3章：栈和队列 |
   | 最短路径 | 第7.3章：图最短路径 |
   | 哈夫曼树 | 第6.2章：哈夫曼树和树与森林转换 |

4. 在资料列表点击“用于问答”，确认进入同一课程的资料问答并带入资料范围。要体验 AI 生成回答，请在本机 `.env` 按根目录 `.env.example` 配置问答模型，重启服务后发问；不要把自己的密钥上传 GitHub。

**无需模型密钥即可体验**：课件导入、普通解析、关键词检索、原文和引用核对。**需要额外配置外部 API**：AI 生成回答、向量检索（Embedding）、重排（Rerank）和自动 OCR。导入已有的图片补录不代表已启用自动 OCR；没有配置这些服务时，请使用关键词检索，不能把无密钥模式当作完整模型问答演示。

## 内容边界

370张不同图片已逐图分类，44张标记为部分转写（包含2张因公式字符严重重叠而无法辨认的图片）。7张教学动画各抽查8帧，没有逐帧抄录。装饰、场景照片、管理截图和无法辨认的内容只留核查记录，不作为课程检索正文。部分源图中的疑似错误或前提缺失保留核对提示。

这是带来源标记的辅助视觉整理，未独立人审，不等于自动OCR服务已经配置。向量、重排及问答生成仍使用各自的服务配置。源PPT重新解析会从原件发布新修订，旧补录保存在历史中，可重新运行本导入工具补入尚未处理的图片。
