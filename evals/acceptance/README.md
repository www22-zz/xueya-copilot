# F 原创离线验收集

版本：`F-acceptance-v1`，2026-10-17。资料与问题由 AI 辅助原创，用于软件验收，不是实际高校课件、教师审定题库或独立学习效果研究。没有拷贝 Open Notebook 的课程数据。基础知识可参照 [Python 数据结构教程](https://docs.python.org/3/tutorial/datastructures.html)、[bisect](https://docs.python.org/3/library/bisect.html)、[heapq](https://docs.python.org/3/library/heapq.html)。公开发布前仍需项目负责人确认项目许可证及材料发布范围。

`dataset.json` 冻结完整正文、问题、参考答案和原文摘录；SHA256 为 `24f7815d71d5ca6f6eeeb0f85803785a7dacd0cc84408aafc6d2bb94e6a06815`。同名 Markdown 是可上传资料。黄金证据按文档名和原文摘录标注，不绑定分块 ID。所有标注状态均为 `needs-human-review`。

当前规模的目的为覆盖软件行为与构建可复现基线，未作统计功效分析。不能声称 60 题证明总体准确率，也不能为凑够 200 题重复改写。后续真实课程集须独立标注，按资料/章节分组留出测试集；改进已看过的这份测试集之后，它只能用于回归，必须另建未见测试集评估泛化。

## 生成与运行

在项目根目录，用安装好 `requirements.lock` 的 Python 运行：

```powershell
python -m scripts.build_quality_materials
python -m scripts.check_quality --split test --repeats 3
python -m scripts.run_c_local_experiments --output test-results/f-quality/c-rules
```

生成目录为 `test-results/f-quality/materials`，包含 DOCX、文本 PDF、图片 PDF、PNG、表格/代码/公式、长文及注入样本。扫描样本只有几何图形、没有可读文字，专门验证无文本层时不会捏造抽取结果，**不能评价 OCR 正确率**。这些原创建模材料不会包含私人数据库或密钥；生成和评测不会调用模型。

评测使用主平台临时数据库和真实上传/解析作业，比较固定 600 字符、80 字符重叠的分块与当前结构分块；共享词法评分、top-k=6、2000 UTF-8 字节摘录预算。该预算是字节数而非模型 token 数。结构服务包含数据库及版本检查，简单基线没有，耗时不能用于断言算法本身快慢。

`results-2026-10-17` 保存首次实际结果、逐题召回与位置、待人工审核表、C 合成规则实验。元数据记录运行时基线提交和工作区有改动；它是提交前运行的真实结果，不伪造为提交后或 CI 结果。最终代码版本由包含这些文件的 Git 提交确定。

## 指标与人工复核

- 全部证据召回：正例中要求的所有黄金摘录均进入预算内上下文的比例。
- 摘录召回：召回黄金摘录数 / 黄金摘录总数；冲突题有两段。
- MRR：正例第一段黄金证据倒数排名的均值；未命中计零。
- 不可答无证据率：负例没有检索结果的比例；相关材料被召回也可能正确拒答，因此不是幻觉率或回答准确率。
- 引用位置：返回 start/end 必须截取出相同 quote。位置正确并不代表引用支持生成结论。
- 延迟：同一次本地运行，每题重复三次的温查询 P50/P95；不含网络模型，不等于完整回答延迟。

人工审核请复制 `human-review.csv`，由审核人逐条打开原文，填写姓名、认可/修订/驳回及理由。重点检查问法歧义、冲突的两面证据、未记载是否真的未记载。当前审核列均留空，不能在报告中称为人工认可。真实模型阶段还要单独保存问题、检索上下文、模型答案、逐结论支持性、错误拒答、调用次数/账单与审核意见；必须先取得当次费用预算。
